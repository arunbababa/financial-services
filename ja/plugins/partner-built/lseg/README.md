# LSEG 金融分析プラグイン

LSEGの金融データと分析機能で、債券評価、利回りカーブ分析、為替キャリー取引評価、オプション評価、マクロダッシュボード作成を行う。

<a id="what-this-plugin-does"></a>
## このプラグインの機能

LSEGの金融分析MCPツールを、一般的な金融分析業務向けの8つの高水準のワークフローにまとめる。ツールを1つずつ個別に呼ぶのでなく、各コマンドが4〜5ツールを連携させ、まとまった分析を作る。

<a id="commands"></a>
## コマンド

| コマンド | 説明 |
|---------|-------------|
| `/analyze-bond-rv` | スプレッド分解とシナリオ・ストレステストによる債券の相対価値分析 |
| `/analyze-fx-carry` | スポット、フォワード、ボラティリティ曲面、過去の状況による為替キャリー機会の評価 |
| `/research-equity` | コンセンサス予想、ファンダメンタルズ、価格実績をまとめた株式調査 |
| `/analyze-swap-curve` | 国債・インフレ情報を重ね、カーブ取引案を探すスワップカーブ分析 |
| `/analyze-option-vol` | ボラティリティ曲面、グリークス、インプライド対実現ボラティリティの比較 |
| `/review-fi-portfolio` | 価格評価、キャッシュフロー、シナリオ分析による債券ポートフォリオのレビュー |
| `/macro-rates` | 経済指標、利回りカーブ、スワップスプレッドのマクロ・金利ダッシュボード |
| `/analyze-bond-basis` | CTD特定とインプライド・レポレートによる債券先物ベーシス分析 |

<a id="skills"></a>
## スキル

各コマンドに対応するスキルが、詳細な専門知識を提供する。

| スキル | 専門知識 |
|-------|-----------------|
| `bond-relative-value` | スプレッドの枠組み、Gスプレッド・Zスプレッド・OAS、割高・割安分析 |
| `fx-carry-trade` | キャリーの仕組み、キャリー対ボラティリティ比率、G10・新興国のキャリー動向 |
| `equity-research` | IBESコンセンサス解釈、ファンダメンタルズ分析、評価指標 |
| `swap-curve-strategy` | スワップカーブ構築、カーブ取引、実質金利分析 |
| `option-vol-analysis` | ボラティリティ曲面の解釈、SABRモデル、グリークス、インプライド対実現ボラティリティ |
| `fixed-income-portfolio` | ポートフォリオ分析、キー・レート・デュレーション、キャッシュフロー分析、シナリオテスト |
| `macro-rates-monitor` | マクロ指標、利回りカーブ形状、実質金利、金融環境 |
| `bond-futures-basis` | CTDの仕組み、ベーシス計算、インプライド・レポ、受渡オプション |

<a id="integrations"></a>
## 外部連携

**LFA MCP Server**へ接続し、次の分野のLSEG金融データ・分析を利用する。

- **債券価格評価** — 債券・債券先物の価値評価
- **FX価格評価** — スポット・フォワードレート
- **カーブ** — 金利・クレジット・インフレ・為替フォワードのカーブ
- **スワップ** — 金利スワップの価格評価
- **オプション** — 全グリークスを伴う評価
- **ボラティリティ** — 為替・株式のインプライド・ボラティリティ曲面
- **定量分析** — アナリスト予想、企業ファンダメンタルズ、株価、マクロデータ
- **時系列** — 過去の価格要約
- **YieldBook** — 債券属性、キャッシュフロー、シナリオ、リスク分析

全ツールの参照情報は [CONNECTORS.md](CONNECTORS.md) を参照。
