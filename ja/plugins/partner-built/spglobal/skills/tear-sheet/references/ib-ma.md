# 投資銀行・M&A向け企業要点資料

<a id="purpose"></a>
## 目的
取引のコンテキストに関する企業プロファイル - 潜在的なターゲット、買収者、またはピッチブックに含める。戦略的位置付け、セグメントの詳細、ビジネス関係、M&A 活動に重点を置きます。投資理論ではなく、取引倍率に基づく評価。

**デフォルトのページ長:** 1 ～ 2 ページ。 IB 企業のプロフィールは、特にセグメントや M&A データが豊富な場合には、2 ページ目にはみ出ることがよくあります。

<a id="query-plan"></a>
## クエリプラン

これらのクエリから始めてください。結果が不完全な場合は分解してフォローアップします。

**クエリ 1 — プロフィール + ID:**
「【会社】事業内容 本社 設立 従業員 業種 業種 所有構造 大株主」
→ヘッダー、事業概要
→ **すぐに** `/tmp/tear-sheet/company-profile.txt` に書き込みます

**クエリ 2 — セグメント + 財務:**
「[会社] 過去 2 会計年度のセグメント事業単位別の収益、および年間損益計算書の収益、売上総利益、EBITDA、営業利益、純利益、設備投資、フリー キャッシュ フロー、過去 4 会計年度の負債総額、現金および同等物」
→ セグメント内訳 (前年比成長率を計算するには 2 年必要)、財務概要 (4 年をプル、3 つを表示、前年比成長率の計算には最も早い年のみを使用)
→ **生の財務情報をすぐに `/tmp/tear-sheet/financials.csv` に書き込みます**
→ **ただちに** セグメント データを `/tmp/tear-sheet/segments.csv` に書き込みます (セグメント データが返されない場合はスキップします)

**クエリ3：評価と類似企業比較**
ユーザーが特定の比較対象企業を指定した場合は、それぞれをクエリします。
「[競合企業] 企業価値 EV/収益 EV/EBITDA 収益成長率 EBITDA マージン」
それ以外の場合:
競合他社ツールを使用して 3 ～ 5 社の上場同業他社を特定し、それぞれの EV/収益 (NTM)、EV/EBITDA (NTM)、収益成長率 %、および EBITDA マージン % を取得します。
関連項目: 「[企業] 企業価値時価総額 EV/収益 EV/EBITDA 評価倍率」
→ ヘッダー (EV/時価総額)、取引コンプ
→ **会社の倍数を `/tmp/tear-sheet/valuation.csv` に直ちに書き込みます**
→ **すぐにピアデータを `/tmp/tear-sheet/peer-comps.csv` に書き込みます**

**クエリ 4 — M&A 活動:**
「[会社] 買収、売却、完了した取引の過去 5 年間の取引額」
→ 自社取引
→ **すぐに** `/tmp/tear-sheet/ma-activity.csv` に書き込みます

**クエリ 5 — 比較可能なトランザクション (データを取得できる場合):**
クエリ 1 の結果から特定の業界を使用します (例: 「テクノロジー M&A」ではなく「クラウド オブザーバビリティ ソフトウェア M&A 取引」)。ユーザーがコンプを指定した場合は、「[コンプ会社] 買収取引倍率」も試してください。
→ 類似取引
→ **比較可能な取引を `/tmp/tear-sheet/ma-activity.csv` に追加** (自社の取引と区別するために `type=precedent` を追加)

**クエリ 6 — 関係 + 所有権:**
「[会社] 主要顧客 サプライヤー パートナー ビジネス関係 機関投資家 所有権 インサイダー所有権」
→ ビジネス関係、所有権 (データを取得できる場合)
→ **すぐに** `/tmp/tear-sheet/relationships.txt` に書き込みます

<a id="sections"></a>
## セクション

優先順にリストされています。明示的なカットのガイダンスについては、以下の「ページの予算とカット順序」を参照してください。

<a id="1-company-header"></a>
### 1. 会社のヘッダー
トランザクション関連の識別子を含むキーと値のブロック。

| フィールド | 注意事項 |
|---|---|
| 会社名 | 大きくて大胆な |
| ティッカー・取引所 | 上場企業のみ。非上場企業は省略 |
| 本社所在地 | 市、州/国 |
| 設立 | 年 |
| 従業員 | おおよその従業員数 |
| 時価総額 / 評価額 | 公開されている場合は時価総額。非公開の場合は最新の既知の評価額 |
| 企業価値 | |
| 持分構成 | 上場／PE出資（スポンサー名）／同族／その他 |

非上場企業なら「Private Company」を目立つように記し、ティッカーと取引所は省略します。

<a id="2-business-overview"></a>
### 2. 事業概要
**これはピッチブックの段落であり、CIQ の概要ではありません。** データ ツールから会社の説明を貼り付けないでください。ピッチブックの散文を使用して 4 ～ 6 文に書き直します。
- 収益モデルを特徴付ける (定期的か取引的か、サブスクリプションかライセンスか)
- 大規模な顧客ベースに名前を付けます (「フォーチュン 500 銀行の 80% にサービスを提供している」)
- 競合する堀を名前で特定します (「X の独自のデータセット」、「Y を持つ唯一のプロバイダー」)
- 買い手または売り手にとって重要なフレーム成長ベクトル

口調は自信を持って具体的でなければなりません。この段落を読んだ銀行家は、会社の戦略的位置付けをすぐに理解するはずです。

<a id="3-revenue--segment-breakdown"></a>
### 3. 収益とセグメントの内訳
ビジネスユニットまたは製品ラインごとの収益。

| セグメント | 収益 (百万ドル) | 全体の % | 前年比成長率 |
|---|---|---|---|
| 【セグメントA】 | | | |
| 【セグメントB】 | | | |
| **合計** | | **100%** | |

**セグメントデータがない場合：** 表の代わりに2〜3文で売上構成を定性的に説明します（例：「主な売上はサブスクリプションライセンス約70%、専門サービス約30%」）。空の表は不備に見えますが、定性的な説明でも有用な情報を伝えられます。

<a id="4-financial-summary-3-year--ltm"></a>
### 4. 財務概要 (3 年間 + LTM)
列見出しは実際の会計年度にします。**LTM（直近12か月）が取得できたら、最新会計年度の右にLTM列を追加**し、「LTM [quarter end date]」（例："LTM Q3 2025"）と表示します。投資銀行担当者はLTMで評価を照合するため、年度実績だけでは6か月以上古い場合があります。

| メトリック ($M) | 20XX年度 | 20XX年度 | 20XX年度 | LTM [日付] |
|---|---|---|---|---|
| 収益 | | | | |
| 収益成長率 % | | | | |
| 売上総利益 | | | | |
| 粗利率 % | | | | |
| EBITDA | | | | |
| EBITDAマージン% | | | | |
| 営業利益 | | | | |
| 当期純利益 | | | | |
| 設備投資 | | | | |
| フリーキャッシュフロー | | | | |
| FCFマージン% | | | | |

M&Aでは絶対的な規模と同じくらい利益率とFCF転換率が重要です。買い手は効率性とキャッシュ創出力を評価するためです。

**資本構成** (財務概要の下にあるコンパクトなサブテーブル):

| メトリック | 値 |
|---|---|
| 有利子負債合計 | $XXM |
| 現金および同等物 | $XXM |
| 純負債 | $XXM |
| 純負債/EBITDA | X.Xx |
| S&P信用格付け | XX (利用可能な場合) |

すでに取得されている貸借対照表データから取得します。これは、どの銀行会社の会社概要でも標準的なものです。負債総額、レバレッジ比率、信用格付けによって、資金調達の状況がどのようなものかを買い手に伝えます。信用格付けが利用できない場合は、その行を省略します。

<a id="5-trading-comps"></a>
### 5. トレーディングコンプ
企業の評価倍率**と事業指標**を並べます。投資銀行担当者は、倍率を単独ではなく事業指標と組み合わせて使います。

**将来予想倍率を取得できるなら必須です。** ツールがNTM倍率を返したら表に含めます。将来予想データがあるのに実績倍率だけでは大きな不足です。投資銀行担当者は将来利益に基づき案件価格を考えるためです。

**同業他社の列を用意します。** ユーザーが比較企業を指定したら各社に列を設けます。指定がなければ競合企業ツールで上場同業他社を3〜5社特定し、倍率と事業指標を取得して載せます。同業他社との比較がなく対象企業だけの表では、投資銀行の用途には不十分です。

| メトリック | 【会社】 | [コンプ1] | [コンプ2] | [コンプ3] | ピア中央値 |
|---|---|---|---|---|---|
| EV/収益 (NTM) | | | | | |
| EV/EBITDA (NTM) | | | | | |
| 収益成長率 % | | | | | |
| EBITDAマージン% | | | | | |

ピア クエリを試行した後に会社独自の倍数のみが利用可能な場合は、それらを表示し、選択したピア名を表の下にリストします。

非上場企業なら、この節を省略します。

<a id="6-ma-activity"></a>
### 6. M&A活動
2部構成。 **このセクションでは取引額が期待されています** — 銀行家は取引額が不足していることに気づきます。

**厳格な規則：M&Aツールが取引額を返したら、必ず出力に載せます。** 判明している取引額を「Undisclosed」へ置き換えるのはデータの完全性に反します。本当に値が返らない場合だけ「Undisclosed」を使います。

**a) 会社自身の取引:**

**表には独立したDeal Value（取引額）の列が必須です。** NotesやRationaleに金額を埋め込んではいけません。担当者が数値をすばやく確認できるよう専用列を設けます。

| 日付 | ターゲット/売却済み | 取引額 (百万ドル) | 種類 | 理論的根拠 |
|---|---|---|---|---|
| | | | 買収・売却 | |

何も見つからなかった場合: 「過去 5 年間に開示された取引はありません。」

**b) 類似するセクターの取引 (データを取得できる場合):**
前に特定した特定の業界を使用します (例: 「テクノロジー M&A」ではなく「クラウド インフラストラクチャ ソフトウェア M&A」)。ユーザーがコンプを指定した場合は、それらの特定の企業が関与するトランザクションも探します。

| 日付 | 対象企業 | 買収企業 | EV（$M） | EV/売上高 | EV/EBITDA |
|---|---|---|---|---|---|

ツールから利用できない場合: 「比較可能なトランザクション データがデータ ソースから利用できません。」前例の倍数を捏造しないでください。

<a id="7-key-business-relationships"></a>
### 7. 主要なビジネス関係
S&P Capital IQ 関係データを活用します。タイプ別にグループ化:

**顧客:** 上位 3 ～ 5 の指定クライアント
**サプライヤー:** 主要ベンダーおよびテクノロジープロバイダー
**パートナー:** 戦略的提携、販売、共同事業
**競合他社:** 主な競合他社名

各項目に関係の種類と、その意味を説明する括弧書きを付けます（例：「AWS — クラウド基盤（主なホスティング提供元）」「JPMorgan — 顧客（企業向け分析プラットフォーム）」）。名前だけでは役立ちません。戦略的に価値が高く、他の要点資料では不足しがちな節なので、余白を確保してください。

<a id="8-ownership-snapshot-data-permitting--omit-if-tools-return-nothing"></a>
### 8. 所有権のスナップショット (データを取得できる場合、ツールが何も返さない場合は省略します)
ツールが機関の所有権、インサイダー所有権の割合、または上位保有者を返す場合は、コンパクトなブロックを含めます。

上位の機関保有者 (可能な場合): 所有率の上位 3 ～ 5 をリストします。
インサイダー所有権: 合計パーセンテージ。

PE 支援企業の場合は、スポンサー、買収年、所有権の名前を記載します。所有構造は取引の複雑さに直接影響します。広く株式を保有する上場会社、創業者が管理する会社、PE の支援を受ける会社は、それぞれ根本的に異なる取引アプローチを必要とします。

所有権データがツールによって返されない場合は、プレースホルダーを表示するのではなく、このセクションを完全に省略してください。

**経営チームのテーブルは含めないでください。** S&P Global ツールはエグゼクティブ データを返しません。データ整合性ルール 10 を参照してください。トレーニング データからの経営陣名は古くなります。

<a id="page-budget--cut-order"></a>
## ページ予算とカットオーダー

**目標は最大2ページ。** 両ページを使えますが、三ページ目へはみ出してはいけません。超えるなら以下の順に削り、一項目を完全に処理してから次へ進みます。

1. 所有権のスナップショット (セクション 8) — 完全に省略
2. 類似セクター取引 (セクション 6b) — 自社の M&A を維持し、前例をカット
3. ビジネス関係 (セクション 7) — 競合他社上位 3 社 + サプライヤー/パートナー/顧客の上位 2 社に圧縮し、記述子を括弧内のみに削除します
4. 資本構成 (セクション 4) — 純負債/EBITDA を単一行として財務概要にマージします。
5. 比較対象の取引 (セクション 5) — 3 つのピアに削減

絶対に削らない節：事業概要（2）、売上・セグメント内訳（3）、財務概要の主要部分（4）、対象企業自身のM&A取引（6a）。

<a id="formatting-notes"></a>
## メモのフォーマット
- 事業概要とセグメント内訳が視覚的に最も重視されます。
- **M&Aの動向は特徴となる主要セクションです。** M&A表の見出しはアクセント色（#2E75B6）の背景に白の太字とします。標準の#D6E4F0と異なる見出し色を使う唯一の表で、ざっと見ても目に入るようにします。
- **ビジネス関係: スペースが許す場合は余裕を持たせてください。** 各関係グループ間に 6 ポイント、各エントリの完全な説明。ただし、3 ページに到達した場合は、上記のカット順序に従って圧縮します。このセクションは価値が高いですが、最も圧縮可能です。
- 非上場企業の場合、ヘッダー、事業概要、財務、関係が中核を形成します。他のセクションはまばらである可能性があります。
- **2 ページの規律:** レンダリングする前に、ページ数を頭の中で見積もります。ビジネス関係と M&A 活動を合わせて 1 ページを超える場合は、カット オーダーに従ってカットを開始します。
