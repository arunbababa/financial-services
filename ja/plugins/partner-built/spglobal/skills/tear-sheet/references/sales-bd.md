# 営業・事業開発向け企業要点資料

<a id="purpose"></a>
## 目的
営業チームまたは BD チームが顧客とのミーティングに向けて準備するための説明文書。見込み客のビジネスを理解し、リーダーが公に優先していることを理解し、製品/サービスを見込み客のニーズに結び付ける角度を特定することに重点を置きます。財務は規模と軌道に合わせて単純化されます。

これは、最も物語主導の企業要点資料 タイプです。データシートではなく、ブリーフィングメモのようなものです。

**デフォルトのページ長:** 1 ～ 2 ページ。厳密な規則はありません。圧縮よりも読みやすさを優先します。

<a id="query-plan"></a>
## クエリプラン

これらのクエリから始めてください。結果が不完全な場合はフォローアップします。

**クエリ 1 — 会社概要 + 財務:**
「[会社] 事業概要 概要 製品 サービス 本社従業員数 部門別 業種別 売上総利益率 過去 2 会計年度」
→ ヘッダー、会社概要、財務スナップショット
→ **すぐに** `/tmp/tear-sheet/company-profile.txt` に書き込みます
→ **生の財務情報をすぐに `/tmp/tear-sheet/financials.csv` に書き込みます**

**クエリ 2 — 戦略 + 収益:**
「[会社] 最新の決算報告 戦略的優先事項 CEO のコメント ガイダンス 主要な取り組み」
→ 戦略的優先事項
→ **すぐに** `/tmp/tear-sheet/earnings.txt` に書き込みます

**クエリ3：取引関係とニュース**
「[会社] 主要顧客、サプライヤー、パートナー、競合他社、ビジネス関係、最近の買収、パートナーシップの発表」
→ 主な関係、最近のニュース
→ **すぐに** `/tmp/tear-sheet/relationships.txt` に書き込みます

通常は 3 つのクエリで十分です。有名な企業の場合、これらは豊富な結果を返します。小規模または非上場企業の場合、クエリ 2 と 3 はまばらかもしれませんが、問題ありません。クロードは利用可能なものをすべて有用な枠組みに統合しているため、定性的なセクションは依然として価値をもたらします。

<a id="sections"></a>
## セクション

優先順にリストされています。スペースに限りがある場合は下からカットしてください。

<a id="1-company-header"></a>
### 1. 会社のヘッダー
合理化 — 識別のみで、評価指標はありません。

| フィールド | 注意事項 |
|---|---|
| 会社名 | 大きくて大胆な |
| ティッカー・取引所 | 上場企業のみ。非上場企業は省略 |
| 本社 | 市、州/国 |
| 業界・分野 | |
| 従業員 | |
| 直近の年間売上高 | $Bまたは$Mの単位で丸める |
| 時価総額 | 上場企業のみ。非上場企業は省略 |
| 年度収益ガイダンス | 収益データから入手可能な場合。例: 「6～8% の本業的成長」 |
| 年度EPSまたはEPS見通し | 上場企業のみ。`earnings.txt`から取得 |
| 主要財務指標 | 調整後EPS、EBITDA利益率等、代表的な数値を一つ |

フォワード ガイダンスと EPS データはクエリ 2 (収益) から取得されます。ヘッダーを設定するときは、`company-profile.txt` だけでなく、`earnings.txt` からのソースになります。

上端に横長の帯を置きます。企業価値も株価ベータも、この読者には不要です。

<a id="2-company-overview"></a>
### 2. 企業概要
最も重要なセクション。営業担当者はこれを読んで、見込み客をしっかりと把握して会議に臨むべきです。

**CIQ の会社概要を貼り付けないでください。** これは SEC への提出文書のように読み取れ、金融以外の読者を失うことになります。平易な言葉で 3 ～ 5 文に書き直します。
- 会社の事業内容 (投資家の専門用語ではありません。「収益化」ではなく「販売」、「トップライン CAGR」ではなく「年間収益」と言う)
- 彼らの顧客は誰なのか
- どのように収益を得るか
- どこで事業を行うか
- 何が彼らを特徴づけているのか

散文の段落で書きます。金融関係者以外の人は、すべての文を理解する必要があります。

<a id="3-strategic-priorities--management-commentary"></a>
### 3. 戦略的優先事項と経営陣の解説
リーダーシップは現在何に重点を置いていますか? CEO が何について話しているのかを知っていれば、ピッチを調整することができます。

**これは収益の要約ではありません。** 株式調査の企業要点資料と同じ箇条書きを再利用しないでください。テーマ ラベルとサポート データ ポイントを含む 3 ～ 5 つの *戦略的テーマ* を抽出します。

- **AI/データの収益化:** 経営陣は AI 機能に積極的に投資しており、2024 年度には X ドルを研究開発に割り当て、AI を活用した 3 つの新しい製品を発売しています。
- **利益率の拡大:** CEO は業務効率を最優先事項として挙げ、自動化により営業利益率 200bps の向上を目標としました。
- **国際的な成長:** EMEA に新しいオフィスを開設。現在、欧州が売上高に占める割合は 18% から 25% に増加しています。

各箇条書きは、「この会社は現在何を重視しているのか、またそれを裏付ける証拠は何ですか?」に答える必要があります。営業担当者はこれらを読んで、製品を接続する角度をすぐに判断する必要があります。

決算発表データが利用できない場合 (非上場企業では一般的)、ツールが返すニュースや発表から取得した「最近の動向」に置き換えます。

<a id="4-financial-snapshot"></a>
### 4. 財務の要点
情報を絞り、規模、推移、収益性の指標一つだけをコンパクトな一表にします。営業担当者が知りたいのは、企業規模、成長しているか、健全か、の三点です。

| 指標 | FY[前年] | FY[直近] | 前年比変化 |
|---|---|---|---|
| 収益 | | | +X% |
| 粗利率 % | | | +X.Xpp |
| 従業員 | | | |

最大3行です。EBITDA、EV倍率、貸借対照表、純利益は載せません。営業向けの収益性指標は、EBITDAや純利益ではなく売上総利益率が適切です。「直接原価を差し引いてどれだけ残るか」という直感的な指標で、財務の専門知識なしに事業の健全性を示せます。さらに詳細が必要なら株式調査版を依頼できます。

非上場企業では売上高と従業員だけの表でも構いません。営業面談には、規模と成長を示すこの二つのデータで十分です。

<a id="5-key-relationships--ecosystem"></a>
### 5. 主要な関係とエコシステム
営業担当者が見込み顧客の世界を理解し、角度を特定できるようにします。

4 つのラベル付きリスト、それぞれ 1 行の記述子を持つ 3 ～ 5 個の名前:

**顧客:** 販売先。市場参入と共通のターゲット顧客を理解するのに役立ちます。
例: 「JPMorgan Chase — 顧客 (エンタープライズ分析プラットフォーム導入)」

**ベンダー・技術：** 相手が何を購入しているか。置換提案や連携の機会を見つけます。
例: 「AWS — ベンダー (プライマリ クラウド インフラストラクチャ)、Snowflake — ベンダー (データ ウェアハウス)」

**パートナー：** 協業相手。共同販売の切り口や共通の接点を見つけます。
例: 「Deloitte — パートナー (企業クライアント向けの実装)」

**競合他社:** 競合する相手。コンテキストの位置付け。
例: 「ブルームバーグ — 競合他社 (金融データ端末)」

すべてのエントリには括弧で囲まれた記述子が必要です。これにより、担当者は関係が「誰」だけでなく「何を意味するか」を理解できるようになります。

関係データが利用できない場合は、「関係データが利用できません」とメモして次に進みます。

<a id="6-recent-news--developments"></a>
### 6. 最近のニュースと開発
3 ～ 5 個の箇条書き、各 1 文、最新のものから。可能な場合は日付を含めます。 **最新の収益レポートでリードします** — これは営業会議にとって最も重要な最近のイベントであり、他のすべての状況を設定します。次に、M&A、製品の発売、リーダーの交代、大きな勝利。

**節の末尾に「Coming Up:」を付け、今後の重要な契機も含めます。** 次回決算、売却予定、製品発売、投資家向け説明会、規制上の節目等です。自然に連絡するタイミングになり、「Q2にInvestor Dayを予定されているのを拝見して」等、接触理由として有用です。決算説明会の発言と未完了案件を含むM&Aデータから取得します。

<a id="7-conversation-starters-cut-first"></a>
### 7. 会話のスターター (最初にカット)
上記データを統合し、会話のきっかけを質問形式で2〜3件提案します。**各質問は第3節の具体的な戦略的優先事項を参照**し、どこにでも当てはまる質問は避けます。

**各スターターに推奨されるペルソナをタグ付けします** — 例: (CTO)、(CFO)、(CDO)、(データ責任者)、(エンジニアリング担当副社長)、(調達責任者)。担当者と CTO のミーティングには、CFO とのミーティングとは異なるオープナーが必要です。ユーザーが会議の相手を指定した場合は、そのペルソナのみのスターターを生成します。

例:
- *(CTO/CDO)* 「前回の決算説明会で [セクション 3 の特定の AI イニシアチブ] について言及しましたが、それは [関連するニーズ] にどのような影響を与えていますか?」
- *(CFO/COO)* 「[セクション 3 の利益拡大目標] に関して、そのスケジュールを加速できるツールを評価していますか?」
- *(戦略/経営企画・M&A担当担当副社長)* 「[会社] が最近 [ターゲット] を獲得したことに気付きました。それによって [能力] に対するあなたのアプローチは変わりますか?」

ユーザーがどのような製品/サービスを販売しているかを説明した場合は、見込み客の優先順位をその商品に結び付けるように調整します。そうでない場合は、見込み客の戦略的テーマに基づいたものにしておきますが、ソリューションの枠組みとしては一般的なものにしてください。

**検証テスト:** 各会話スターターを完成させる前に、企業要点資料から抽出された特定の番号、日付、製品名、または取り組み名が少なくとも 1 つ含まれていることを確認してください。この分野のどの企業にも当てはまりそうな質問は、会話のきっかけにはなりません。 「AIについてどう考えていますか？」ジェネリックです。 「御社の CEO は、2018 年以降の AI 投資が 10 億ドルで、iLEVEL 自動取り込み機能が 20% 採用されていると述べましたが、それによってアナリストのワークフローはどのように変化していますか?」具体的であり、準備を示しています。

このセクションはクロードの合成であり、ツールからの生データではありません。明確にラベルを付けます。

<a id="formatting-notes"></a>
## メモのフォーマット
- **これは、最も温かく、最も読みやすい企業要点資料である必要があります。** 厳密な内容ですが、フォーマットはデータ端末ではなく、ブリーフィングメモのように感じられる必要があります。
- 本文: 9pt (サイズ: 18) 全体を使用します。圧縮なし - 密度よりも読みやすさ。
- 行間隔: 本文段落の 1.15 倍 (デフォルトよりわずかに広い)。このテンプレートは、空白が無駄ではなく特徴であるテンプレートです。
- 企業概要と戦略的優先事項に、ページの約40〜50%を使います。
- 財務スナップショット: 視覚的にコンパクトで、二次的に目立つ。小さくて清潔に保ちましょう。
- 主要な関係: 記述子を表示したまま垂直方向のスペースを節約するには、2 列のレイアウト (顧客 + ベンダーを左側、パートナー + 競合他社を右側) を検討します。
- 会話のスターター: インデントされたブロック スタイルの箇条書きを使用します。これらはドキュメントの成果であり、視覚的に目立つ必要があります。
