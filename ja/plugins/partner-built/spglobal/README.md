# S&P グローバル プラグイン

このプラグインは、事前に構築された一連のスキルを介して、S&P Global の財務データと分析を AI ワークフローに直接導入します。これは、信頼できる S&P Global データに基づいた AI 支援の調査、分析、文書生成を求める金融専門家向けに設計されています。

スキルはオープン スタンダード (MCP) に基づいて構築されており、AI プラットフォームとエージェント フレームワーク全体で機能するように設計されています。このプラグインは Claude Cowork 標準に従っていますが、すべてのスキルと基礎となるデータ層はプラットフォームに依存しません。これらのスキルを別の環境でも使用したい場合は、使用してください。

私たちは、どの組織にも独自のニーズがあることを認識しています。これらのスキルは、完成品の作成を開始するための出発点となります。企業固有のプロセス、テンプレート、データのニーズに合わせてプロンプト、出力、ワークフローを調整することをお勧めします。

このプラグインのスキルは現状のまま提供されます。生成された出力とデータが正しいことは保証されません。 **LLM によって生成された出力が正しいかどうかを常に確認してください。**

<a id="skills-contained"></a>
## 含まれるスキル

<a id="tearsheets"></a>
### 企業要点資料（Tearsheets）
**必須**: [S&P Global LLM 対応 API](https://www.marketplace.spglobal.com/en/solutions/kensho-llm-ready-api-%28a156fe9f-5564-4f60-a624-95d8645dc98f%29) サブスクリプション

S&P Capital IQのライブデータに基づき、1〜2ページの企業要点資料を、書式を整えたWord文書で生成します。用途に合わせて最適化した四種類の読者に対応します。
* 株式調査：バイサイド／セルサイドのアナリスト向けに投資仮説の要点を示す
* 投資銀行業務 / M&A: 取引における会社概要
* 経営企画・M&A担当（Corporate Development）：社内の戦略担当向けに買収候補企業の概要を示す
* 販売/事業開発: 商業チーム向けの顧客会議の準備

**プロンプト例：**「Palantirの事業開発向け企業要点資料を作成して」

<a id="industry-transaction-summaries"></a>
### 業界取引の概要
**必須**: [S&P Global LLM 対応 API](https://www.marketplace.spglobal.com/en/solutions/kensho-llm-ready-api-%28a156fe9f-5564-4f60-a624-95d8645dc98f%29) サブスクリプション

S&P Capital IQ の取引データに基づいて、セクター内または特定の企業の最近の M&A および取引活動を要約します。市場マッピング、ピッチの準備、競合情報の収集に役立ちます。

**プロンプトの例**: 「データ インフラストラクチャ領域における最近のトランザクションの概要」

<a id="earnings-previews"></a>
### 決算プレビュー
**必須**: [S&P Global LLM 対応 API](https://www.marketplace.spglobal.com/en/solutions/kensho-llm-ready-api-%28a156fe9f-5564-4f60-a624-95d8645dc98f%29) サブスクリプション

次の決算発表に向け、コンセンサス予想、直近の会社側見通し、アナリストの見方、注目事項を含む構造化された決算プレビューを生成します。情報源はすべてS&P Capital IQです。

**プロンプト例：**「Salesforceの決算プレビューを作成して」

<a id="how-to-use"></a>
## 使用方法
プラグインとスキルを使用するには、[Capital IQ Pro](https://www.spglobal.com/market-intelligence/en/solutions/products/sp-capital-iq-pro) または [S&P Global LLM-ready API](https://www.marketplace.spglobal.com/en/solutions/kensho-llm-ready-api-%28a156fe9f-5564-4f60-a624-95d8645dc98f%29) サブスクリプションのいずれかで、S&P Global データにアクセスする必要があります。 

LLM 対応 API は、MCP サーバー経由で Claude または他のアプリケーションに簡単に統合できます。 [次の手順](../../../../plugins/partner-built/spglobal/docs.kensho.com/llmreadyapi/mcp/third-party/claude) に従って設定してください。 

<a id="in-cowork"></a>
### コワーク内
有料の Claude プラン (Pro、Max、Team、または Enterprise) と、macOS または Windows 用の Claude デスクトップ アプリが必要です。

1. Claude Desktop を開き、**Cowork** タブに移動します
1. **プラグインを使用してカスタマイズ** をクリックします
1. [プラグインの参照] で、**個人** を選択します
1. **プラス記号「+」** をクリックしてプラグインを追加します
1. プロンプトが表示されたら、S&P Global 認証情報を使用して認証します

インストールすると、必要なものを自然言語で説明するだけで、関連するスキルが自動的に有効になります。チャット内で「 / 」と入力して特定のスキルを明示的に呼び出して、使用可能なコマンドを確認することもできます。

会社のワークフロー、テンプレート、または用語に合わせてプラグインをカスタマイズするには、インストールされているプラグインを表示しているときに [**カスタマイズ**] をクリックします。私たちはこれを奨励します。デフォルトは出発点であり、処方箋ではありません。

<a id="in-claude-desktop-individual-skills"></a>
### Claude Desktopで個別のスキルを使う
完全なプラグインを使用せずに Claude Desktop に個別のスキルをインストールするには:

1. **設定**を開きます
1. **能力 → スキル** に移動します
1. [**追加**] をクリックします
1. このリポジトリからスキル ファイルをアップロードします

スキルは、アップロードされるとすぐにクロード デスクトップ セッションで使用できるようになります。ニーズに応じて 1 つまたは複数をインストールできます。

<a id="in-claude-code-individual-skills"></a>
### Claude Codeで個別のスキルを使う

[Claude Code ドキュメント](https://code.claude.com/docs/en/discover-plugins#add-from-github) の指示に従ってください。

<a id="other-platforms"></a>
### その他のプラットフォーム
このリポジトリのスキルはマークダウン ファイルです。カスタム命令、システム プロンプト、またはナレッジ ファイルのアップロードをサポートする AI プラットフォームであれば、それらを使用できます。メカニズムはプラットフォームによって異なりますが、原則は同じです。スキル コンテンツをロードして、モデルが永続的なコンテキストとして持つようにします。

**ChatGPT**: スキル コンテンツをカスタム手順 (設定 → ChatGPT のカスタマイズ) に貼り付けるか、プロジェクト内のナレッジ ファイルとしてアップロードするか、カスタム GPT の構成に追加します。カスタム命令はセッション全体にグローバルに適用されます。プロジェクト レベルのファイルは、コンテキストを特定のワークフローにスコープします。

**Microsoft Copilot**: Copilot 構成 (M365 Copilot、Copilot Studio など) に応じて、スキルのコンテンツをカスタム プロンプトまたはシステム命令に貼り付けます。 Copilot Studio を介したエンタープライズ展開では、ナレッジ ソースを直接アップロードできます。

**その他のプラットフォーム**: プラットフォームがシステム プロンプトまたは永続的な命令レイヤーをサポートしている場合は、そこにスキル マークダウンを貼り付けます。ファイルベースのナレッジ検索をサポートしている場合は、スキル ファイルをアップロードします。スキルは単純なマークダウンであり、特別なフォーマットやツールは必要ありません。
