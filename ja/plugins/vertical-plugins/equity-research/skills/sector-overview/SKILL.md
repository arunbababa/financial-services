<a id="sector-overview"></a>
# セクター概要

<a id="workflow"></a>
## ワークフロー

<a id="step-1-define-scope"></a>
### 手順1：範囲を定める

- **セクター・下位分類：** 業界と定義の細かさ。
- **目的：** 顧客レポート、内部調査、提案資料、案の生成。
- **深さ：** 概要5〜10ページ、詳細20〜30ページ。
- **切り口：** 中立的な概況か、「AI基盤整備」等のテーマ仮説か。
- **対象：** 上場のみか、非上場も含むか。

<a id="step-2-market-overview"></a>
### 手順2：市場概要

**市場規模・成長**
- 出典付きTAM。
- 過去5年CAGR。
- 予想成長率・主要前提。
- 製品・地域・最終市場・顧客種別の区分。

**業界構造**
- 分散型か集約型か。上位5社シェア。
- 価値が蓄積する場所を示すバリューチェーン。
- 事業モデル（サブスクリプション、取引、ライセンス、サービス）。
- 参入障壁（資本、規制、技術、ネットワーク効果）。

**主要動向・要因**
- 3〜5の長期的追い風。
- 向かい風・リスク。
- 技術による破壊の方向。
- 規制動向。
- M&A・集約の動向。

<a id="step-3-competitive-landscape"></a>
### 手順3：競争環境

**上位5〜10社の概要：**

| 企業 | 売上 | 成長 | EBITDA利益率 | シェア | 主な差別化 |
|---------|---------|--------|--------------|-------------|-------------------|
| | | | | | |

各社を短く説明する。
- 事業説明2〜3文。
- 戦略的位置・競争上の堀。
- 最近の決算・M&A・製品投入。
- 評価概要（PER、EV/EBITDA、EV/売上）。

**競争の動態**
- 価格・製品・サービス・流通の何で競うか。
- 誰が、なぜシェアを増減させているか。
- 新規・隣接企業による破壊リスク。

<a id="step-4-valuation-context"></a>
### 手順4：評価水準の背景

- 現在・過去範囲の市場取引倍率。
- プレミアム・ディスカウントの要因（成長・利益率・市場の位置）。
- 最近のM&A取引倍率。
- 市場全体との比較。

<a id="step-5-investment-implications"></a>
### 手順5：投資への示唆

- 最もよいリスク・リターンの機会はどこか。
- このセクターでどのテーマへ投資できるか。
- 強気・弱気の主要論争。
- セクターの見方を変え得るきっかけ。

<a id="step-6-output"></a>
### 手順6：出力

- Word・PowerPoint：
  - 市場概要・規模。
  - 競争環境マップ。
  - 企業比較表。
  - 評価概要。
  - 市場成長、シェア推移、評価履歴の主要図。
- 詳細企業データのExcel付録。

<a id="important-notes"></a>
## 重要事項

- 全市場規模データの出典として調査会社・方法を示す。
- TAMへの過熱した期待と現実的な対象市場を分ける。
- 概況はすぐ古くなる。日付を記し、古い可能性のあるデータを示す。
- 図は必須。市場規模ウォーターフォール、競争位置マトリクス、評価散布図を使う。
- 顧客向けなら、M&A候補特定・競争上の位置・参入など、その状況に合わせて「それが何を意味するか」を伝える。
