# カバレッジ開始レポートの品質管理チェックリスト

カバレッジ開始レポートを提出する前に、以下の項目がすべて完了していることを確認してください。

<a id="critical-minimums---reports-must-meet-these"></a>
## 重要な最小値 - レポートはこれらを満たす必要があります

**重要：次のいずれかに該当する場合は納品しないこと：**
- ❌ DOCX レポートが 30 ページ未満 → 不完全
- ❌ 埋め込まれたチャートが 25 未満 → 不完全
- ❌ 包括的なテーブルが 12 未満 → 不完全
- ❌ 10,000 ワード未満 → 不完全
- ❌ XLS 財務モデルがない → 成果物がありません
- ❌ チャートはテキストによる説明であり、実際の PNG/JPG ファイルではありません → 重大なエラー

<a id="deliverables-checklist"></a>
## 成果物のチェックリスト

- [ ] DOCXレポートファイルが作成されました
- [ ] XLS財務モデルファイルが作成されました
- [ ] 両方のファイルに適切な名前が付けられています: `[Company]_Initiation_Report_[Date].docx` および `[Company]_Financial_Model_[Date].xlsx`

<a id="docx-report---length--content"></a>
## DOCX レポート - 長さと内容

**長さの確認:**
- [ ] レポートは 30 ～ 50 ページです (最終文書のページ数を数えます)
- [ ] ワード数は10,000～15,000ワードです
- [ ] 30 ページ未満の場合: 停止してコンテンツを追加します

**視覚要素:**
- [ ] 25 ～ 35 個のチャートが埋め込まれています (数える: _____ 個のチャート)
- [ ] すべてのグラフは実際の PNG/JPG 画像ファイルです (テキストによる説明ではありません)。
- [ ] 12 ～ 20 の包括的なテーブルが含まれています (テーブル数: _____ )
- [ ] グラフと表が全体に散在しており、最後にグループ化されていない

**チャートの要件:**
- [ ] 製品別売上高グラフ: 積み上げエリア形式 ✓
- [ ] 地域別売上高グラフ: 積み上げ棒形式 ✓
- [ ] DCF 感度: カラーコーディング付きの 2 方向ヒート マップ ✓
- [ ] バリュエーション・フットボールフィールド: 横棒グラフ ✓
- [ ] 他のすべてのチャートは実際の画像ファイルです ✓

**テーブルの要件:**
- [ ] 5 年間の過去 + 5 年間の予測を含む完全な損益計算書 (40 ～ 50 行)
- [ ] 完全なキャッシュ フロー計算書 (30 ～ 40 行)
- [ ] 全貸借対照表 (35 ～ 45 行)
- [ ] 製品別売上高テーブル (20 ～ 30 行)
- [ ] 地域別売上高テーブル (15 ～ 20 行)
- [ ] チャネル別売上高テーブル (10 ～ 15 行)
- [ ] 統計概要を含む比較会社表（最大値/第75百分位/中央値/第25百分位/最小値）
- [ ] DCF計算表（30～40行）
- [ ] WACC計算表（8～10行）
- [ ] 2 つの感度テーブル
- [ ] 2～3 個の追加の財務/競争力表

<a id="docx-report---structure"></a>
## DOCX レポート - 構造

**ページ 1 の要件:**
- [ ] 「INITIATING COVERAGE」ヘッダーが存在します (「Company Update」ではありません)
- [ ] 投資判断の根拠を中心としたタイトル (「好調な第 4 四半期結果」のようなイベント主導型ではない)
- [ ] 投資判断、株価、目標株価、52週間の株価レンジ、時価総額、EVを含む投資判断ボックス
- [ ] ■ 文字と太字のヘッダーを含む 3 ～ 4 個の段落長の箇条書き
- [ ] 2 ～ 3 年間の過去および 2 年間の予測を含む財務および評価指標の表
- [ ] 表には、実績を表す「A」の接尾辞、推定を示す「E」の接尾辞が示されています
- [ ] すべてのビジュアルのソース行

**コンテンツセクション:**
- [ ] 目次 (ページ 2)
- [ ] 投資判断の根拠とリスク (3 ～ 5 ページ)
- [ ] 会社概要 (6 ～ 12 ページ) には以下が含まれます。
  - [ ] 会社概要
  - [ ] 歴史とマイルストーン
  - [ ] 経営陣の略歴 (幹部 3 ～ 4 名で各 300 ～ 400 ワード)
  - [ ] 製品・サービス詳細
  - [ ] 競争環境
- [ ] 財務分析と予測 (10 ～ 15 ページ)
- [ ] バリュエーション分析 (8-12 ページ)
- [ ] 仮定セクション (すべての予測の前提を文書化する 2,000 ～ 3,000 ワード)
- [ ] シナリオ分析 (ブル/ベース/ベアパラメータを含む 1,500 ～ 2,000 ワード)
- [ ] データソースと参考ページを含む付録

<a id="docx-report---formatting"></a>
## DOCX レポート - フォーマット

**図と表の書式設定:**
- [ ] すべての図の上には「図 X - [会社] [説明的なタイトル]」というキャプションが付いています。
- [ ] すべての図の下にソース行があります: 「出典: [日付付きの特定のソース]」
- [ ] 連続した図の番号付け (図 1、2、3... 隙間なし)
- [ ] すべてのテーブルには網掛け付きのヘッダー行があります
- [ ] すべてのテーブルの下部にソース行があります
- [ ] すべての年は実績表記に「A」、推定表記に「E」を使用します

**プロフェッショナルな書式設定:**
- [ ] 全体を通して一貫したフォント (Calibri、Arial、または類似のもの)
- [ ] ページ番号付きのヘッダーとフッター
- [ ] 高密度レイアウト: ページ カバレッジ 60 ～ 80%、余白は最小限
- [ ] すべてのページにテキストとビジュアル (グラフまたは表) の両方が含まれています
- [ ] プロフェッショナルなビジネスレポートテンプレートを使用

<a id="citations--sources--critical"></a>
## 引用と出典 ⭐⭐⭐ 重要

**出典の帰属:**
- [ ] すべての図には文書名と日付が記載された特定の情報源が含まれています
- [ ] すべての表には文書参照を含む特定のソースが含まれています
- [ ] 本文全体にわたる主要な統計には出典を示す脚注が付いています
- [ ] 一般的な「会社データ」だけではなく、具体的なものでなければなりません

**ハイパーリンク:** ⭐⭐⭐ 必須
- [ ] すべての URL はクリック可能なハイパーリンクです (プレーンテキストではありません)
- [ ] EDGAR ビューアにハイパーリンクされた SEC 提出書類
- [ ] 決算説明会の書き起こしにハイパーリンクを設定（Seeking Alpha または企業IR）
- [ ] 企業の IR ページにハイパーリンクされたプレスリリース
- [ ] PDF URL にハイパーリンクされたプレゼンテーション
- [ ] 業界レポートのハイパーリンク (公開されている場合)
- [ ] 購読データ (ブルームバーグ、ファクトセット) に「(購読が必要)」と記載されている
- [ ] 生の URL はどこにも表示されず、すべてハイパーリンクとしてフォーマットされています
- [ ] 3 ～ 5 個のサンプル ハイパーリンクをテストして、機能することを確認します (Ctrl+クリック)

**参考ページ:**
- [ ] レポートの最後にある「データ ソースと参照」ページ
- [ ] レポートで使用されるすべてのソースをリストします。
- [ ] カテゴリ別に整理されたソース (SEC 提出書類、決算説明会の書き起こしなど)
- [ ] すべてのソースには日付が付いています
- [ ] すべてのソースにはクリック可能なハイパーリンクがあります (該当する場合)

<a id="xls-financial-model---structure"></a>
## XLS 財務モデル - 構造

**ファイル構造:**
- [ ] Excel ワークブックの 15 個以上のタブ
- [ ] タブには次のものが含まれます: エグゼクティブ サマリー、前提条件、過去の財務状況、売上高モデル、営業費用、損益計算書、貸借対照表、キャッシュ フロー、補助明細、DCF 評価、類似企業比較分析、類似取引事例、シナリオ、感応度分析、チャート

**フォーマット:**
- [ ] ハードコードされた入力の青いテキスト
- [ ] 数式の黒文字
- [ ] 他のシートへのリンクの緑色のテキスト
- [ ] 枠線とシェーディングを使用したプロフェッショナルな書式設定
- [ ] 明確なセクション見出しとラベル

**モデルの機能:**
- [ ] すべての数値が流れる (仮定の変更 → モデル全体の更新)
- [ ] DCF は仮定と予測にリンクします
- [ ] 循環参照やエラーがない
- [ ] すべての重要なセル/範囲には名前が付けられています
- [ ] 感度テーブルは動的に動作します

<a id="xls-financial-model---content"></a>
## XLS 財務モデル - 内容

**予測:**
- [ ] 3 ～ 5 年間の履歴データ
- [ ] 5年間の将来見通し（+1年度から+5年度）
- [ ] 製品、地域、チャネルごとに分類された売上高
- [ ] 40 ～ 50 項目の完全な損益
- [ ] 30 ～ 40 項目の完全なキャッシュ フロー
- [ ] 35 ～ 45 項目の完全な貸借対照表

**評価:**
- [ ] すべての計算を示した完全な DCF モデル
- [ ] すべてのコンポーネントを使用した WACC の計算
- [ ] ターミナルバリューの計算
- [ ] 類似会社分析（5～10社）
- [ ] 類似取引事例分析（5～10件）
- [ ] シナリオ分析 (強気/ベース/弱気)
- [ ] 2 つの感度テーブル

<a id="cross-file-consistency"></a>
## ファイル間の一貫性

**重要**: DOCX と XLS の間で数値が正確に一致する必要があります。

- [ ] 売上高の数値は両方のファイルで一致します
- [ ] EPS の数値は両方のファイルで一致します
- [ ] 両方のファイルで利益率が一致する
- [ ] 評価数値は両方のファイルで一致します
- [ ] 両方のファイルで目標株価が一致する
- [ ] 両方のファイルですべての予測年が一致します

**検証方法**: DOCX レポートと XLS モデルの間で 10 ～ 15 個の主要な数値をスポット チェックします。

<a id="content-quality"></a>
## コンテンツの品質

**投資判断の根拠:**
- [ ] 3～5 つの明確な投資判断を支える柱
- [ ] 各柱は特定のデータと定量化によって裏付けられています
- [ ] 各柱ごとに数値化された財務効果
- [ ] 時期を明示したカタリスト

**分析の深さ:**
- [ ] 包括的なビジネスモデル分析
- [ ] 詳細な競合評価
- [ ] 3～5年の財務傾向を分析
- [ ] 8～12 個のリスクが特定され、定量化されました
- [ ] 経営陣の分析 (幹部あたり 300 ～ 400 ワード)

**前提:**
- [ ] すべての仮定を文書化した 2,000 ～ 3,000 ワード
- [ ] カテゴリ/地域別売上高成長の仮定
- [ ] 利益率変化の要因を示すブリッジを伴う利益率の前提
- [ ] 運転資本の仮定
- [ ] 設備投資の想定
- [ ] 各仮定には特定の定量化があります

**シナリオ:**
- [ ] シナリオ分析に関する 1,500 ～ 2,000 ワード
- [ ] 特定のパラメータとカタリストを備えたブルケース
- [ ] 詳細な根拠を含む基本ケース
- [ ] 特定のトリガーを備えたベアケース
- [ ] 各シナリオの確率評価

<a id="writing-quality"></a>
## 文章の品質

**スタイル:**
- [ ] 数字でリードする (「売上高が好調」ではなく「売上高が15%増加して12億ドル」)
- [ ] 「versus」ではなく「vs.」を使用する
- [ ] 直接的かつ簡潔であること
- [ ] 全体を通して機関投資家向けの専門的な文体
- [ ] くだけた言葉遣いは禁止

**精度:**
- [ ] ティッカーシンボルにタイプミスはありません
- [ ] 会社名の誤字はありません
- [ ] すべての日付は正確です
- [ ] すべての計算が検証されました
- [ ] グラフはテキストの説明と一致します
- [ ] すべての数値が正しくフォーマットされている ($ 記号、% 記号、カンマ)

<a id="pre-delivery-final-check"></a>
## 納品前の最終チェック

この簡単な最終レビューを実行してください。

1. **成果物**: DOCX ファイルと XLS ファイルの両方が作成されました ✓
2. **長さ**: DOCX は 30 ～ 50 ページです ✓
3. **チャート**: 25 ～ 35 個の実際の PNG/JPG ファイルが埋め込まれています ✓
4. **テーブル**: 12 ～ 20 の包括的なテーブルが含まれています ✓
5. **単語**: 10,000 ～ 15,000 単語 ✓
6. **ハイパーリンク**: 3 ～ 5 個のハイパーリンクをテストします - すべて機能します ✓
7. **クロスチェック**: DOCX と XLS の間で 10 個の数値が一致することをスポット チェック ✓
8. **ページ 1**: 「INITIATING COVERAGE」ヘッダーが存在します ✓

いずれかのアイテムが失敗した場合は、納品しないでください。戻って修正してください。

## 実際の数の検証

**納品前に、実際の個数を入力してください:**

DOCXレポート:
- ページ数: _____ ページ (30 ～ 50 でなければなりません)
- チャート数: _____ チャート (25 ～ 35 でなければなりません)
- テーブル数: _____ テーブル (12 ～ 20 でなければなりません)
- 単語数: _____ 単語 (10,000 ～ 15,000 でなければなりません)

XLSモデル:
- タブ数: _____ タブ (15 個以上である必要があります)
- モデルの対象年数: 過去 _____ 年 + 予測 _____ 年

いずれかのカウントが最小値を下回っている場合は、配信を停止し、配信前にコンテンツを追加します。
