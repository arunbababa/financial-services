# タスク 1: 企業調査 - 詳細なワークフロー

このドキュメントでは、カバレッジ開始スキルのタスク 1 (企業調査) を実行するための段階的な手順を説明します。

<a id="task-overview"></a>
## タスクの概要

**目的**: 企業の事業、経営、競争上の地位、業界、リスクを調査します。

**前提条件**: ✅ なし (完全に独立)
- 会社名またはティッカーシンボルのみ

**出力**: 企業調査ドキュメント (6,000 ～ 8,000 ワード)

---

<a id="data-sources-to-gather"></a>
## 収集するデータソース

<a id="primary-sources-company"></a>
### 一次情報源（会社）
- **SEC 提出書類 (上場企業向け):**
  - 最新の 10-K: 事業内容、リスク要因、MD&A、財務
  - 最近の 10-Q: 四半期ごとの更新
  - DEF 14A (委任状): 役員報酬、取締役会構成
  - 8-K: 重大な出来事、買収、経営陣の交代

- **会社ウェブサイトとIR:**
  - 投資家向けプレゼンテーション
  - 決算説明会の書き起こし (過去 2 ～ 3 四半期)
  - プレスリリース
  - 製品ドキュメント

- **非上場企業の場合:**
  - 会社のウェブサイトとブログ
  - プレスリリースとメディア掲載
  - LinkedIn の経営陣プロフィール
  - 資金調達履歴のための Crunchbase または PitchBook

<a id="secondary-sources-industrycompetitive"></a>
### 二次情報源 (業界/競合)
- 競合他社の Web サイトと SEC への提出書類
- 業界調査レポート (Gartner、Forrester、IDC など)
- ニュース記事と業界出版物
- 市場調査レポート
- 主要幹部の LinkedIn プロフィール

<a id="key-information-to-extract"></a>
### 抽出すべき重要な情報

**重要な情報:**
- 会社設立日、本社、従業員数
- 売上高規模と成長の軌跡 (可能な場合)
- 製品ポートフォリオと価格設定
- 顧客セグメントとケーススタディ
- 経営背景と実績
- 競争環境と市場シェア
- 業界のトレンドと成長の原動力
- 規制上の考慮事項
- 財務指標の概要（10-Kの文章部分から把握するもので、詳細な抽出は行わない）

<a id="step-by-step-research-workflow"></a>
## 段階的な調査ワークフロー

<a id="step-1-initial-data-collection"></a>
### ステップ 1: 初期データ収集

1. **会社の Web サイトから始めましょう**
   - 会社概要/会社ページを読む
   - 製品ページを確認する
   - 顧客の事例を特定する
   - 記載されている主要な指標 (従業員、顧客など) に注目してください。

2. **SEC 提出書類を収集する (上場企業の場合)**
   - SEC EDGAR から最新の 10-K をダウンロード
   - 最新の 10-Q をダウンロード
   - 最新の DEF 14A (委任状) をダウンロード
   - 提出日を記録する

3. **決算資料を読む**
   - 最新の決算説明会の書き起こし
   - 最新の投資家向けプレゼンテーション
   - 過去 12 か月のプレスリリース

4. **基本的な事実を文書化**
   - 創業年月と経緯
   - 本社所在地
   - 従業員数
   - 製品・サービス
   - 主要顧客

<a id="step-2-business-model-analysis"></a>
### ステップ 2: ビジネスモデル分析

1. **売上高の源泉を整理する**
   - その会社は何を売っていますか?
   - 価格はどうなっていますか? (サブスクリプション、トランザクション、ライセンスなど)
   - 誰が支払いますか？
   - 一般的な取引規模はどれくらいですか?

2. **顧客セグメントを理解する**
   - エンタープライズ対中小企業対コンシューマ
   - サービスを提供する業界
   - 地理的分布
   - 顧客集中度（上位10顧客）

3. **市場開拓の文書化**
   - 直販とチャネルパートナーの比較
   - 販売サイクルの長さ
   - 顧客獲得戦略
   - 流通モデル

4. **ユニットエコノミクスを特定する**
   - LTV/CAC (利用可能な場合)
   - 粗利益率
   - 売上高維持率（NRR）
   - 投資回収期間

<a id="step-3-management-research"></a>
### ステップ 3: 経営陣の調査

**3 ～ 4 人の主要幹部のそれぞれについて:**

1. **主要なリーダーを特定する**
   - CEO (常に必須)
   - CFO (常に必須)
   - COO、CTO、またはその他の経営幹部 (2 名追加)

2. **各幹部を調査**
   - LinkedIn プロフィールを探す
   - 背景として DEF 14A を確認してください
   - プレスインタビューを検索する
   - 在職期間に注意する

3. **以下を含む 300 ～ 400 ワードの経歴を書きます。**
   - 現在の役割と責任
   - 以前の役職と会社 (最後の 2 ～ 3 つの役職)
   - 主な成果と実績
   - 学歴と資格
   - 業界経験年数
   - 現在の会社での在籍期間

4. **ガバナンスの評価**
   - 取締役会の構成と独立性
   - 主要な取締役とその経歴
   - 内部者の持株比率
   - 役員報酬体系

<a id="step-4-competitive-intelligence"></a>
### ステップ 4: 競合情報

1. **5 ～ 10 社の競合他社を特定します**
   - 直接の競合他社 (同じ製品/市場)
   - 間接的な競合他社（代替ソリューション）
   - 新興の競合他社（ディスラプター）
   - 10-K で自社の競合他社リストを確認してください

2. **各競合他社を調査する**
   - 競合他社の Web サイトにアクセスする
   - SEC 提出書類を確認します (上場企業の場合)
   - 主な製品とポジショニングに注目してください
   - 差別化要因を特定する
   - 市場シェアの推定 (データが入手可能な場合)

3. **競争力のある枠組みの構築**
   - 主要な側面（価格、機能、規模など）をマップします。
   - 企業の競争上の優位性を特定する
   - 競合上の脆弱性に注意する
   - スイッチングコストとネットワーク効果を評価する

4. **競合に関する洞察を文書化する**
   - 市場のリーダーは誰ですか?
   - この会社は何位にランクされますか?
   - 独自の差別化要因とは何ですか?
   - 競争上の脅威とは何ですか?

<a id="step-5-industry-analysis"></a>
### ステップ 5: 業界分析

1. **業界の定義**
   - 業種分類（NAICS/SIC）
   - 範囲と境界
   - 関連・隣接産業

2. **市場規模を把握する**
   - 獲得可能な最大市場規模（TAM）
   - 事業上アプローチ可能な市場規模（SAM）
   - 現実に獲得可能な市場規模（SOM）
   - 現在の普及率

3. **成長ドライバーを調査する**
   - 過去の市場成長率
   - 予測される成長率 (今後 3 ～ 5 年)
   - 成長を加速/減速させる主なトレンド
   - 業界に影響を与えるテクノロジーの変化

4. **業界構造を理解する**
   - 分散型の市場か寡占化した市場か
   - 参入障壁
   - サプライヤー/バイヤーの力
   - 代替品の脅威
   - 規制環境

<a id="step-6-risk-assessment"></a>
### ステップ 6: リスク評価

4 つのカテゴリにわたって 8 ～ 12 のリスクを特定します。リスクごとに 50 ～ 100 語を書きます。

**企業固有のリスク (4 ～ 6 つのリスク):**
- 実行リスク（経営陣は対応できるか？）
- 顧客集中（上位顧客）
- キーパーソンへの依存
- 製品/技術の陳腐化
- 地理的集中
- 統合リスク（最近のM&Aの場合）

**業界/市場のリスク (3 ～ 4 つのリスク):**
- 競争の激しさ
- 規制の変更
- テクノロジーの破壊
- 市場の飽和

**財務リスク (2 ～ 3 のリスク):**
- 黒字化までの時期
- 資金要件
- 債務水準と財務制限条項（コベナンツ）
- キャッシュバーンレート（利益が出ない場合）

**マクロ経済リスク (2 ～ 3 のリスク):**
- 経済感応度（景気循環かディフェンシブか）
- 金利感応度
- 外国為替エクスポージャー
- 地政学的要因

**各リスクについて:**
- リスクを明確に説明する
- 可能であれば影響を定量化する
- 可能性/重大度に注意してください
- 緩和要因を特定する

<a id="step-7-synthesis-and-writing"></a>
### ステップ 7: 情報の統合と執筆

**次の構造に従ってドキュメントを作成してください:**

1. **会社概要** (800-1,200 ワード)
   - 会社は何をする会社ですか? (わかりやすい英語)
   - 彼らはどうやってお金を稼いでいるのでしょうか？ （ビジネスモデル）
   - 彼らはどこで活動しているのでしょうか？ (事業展開地域)
   - どれくらいの大きさですか? (売上高、従業員数、顧客数)
   - 主要な指標とスケール指標

2. **会社沿革** (800-1,200 ワード)
   - 創業ストーリー（誰が、いつ、なぜ、どこで）
   - 主要なマイルストーンのタイムライン
   - 戦略的な転換または変革
   - 主な買収
   - 最近の動向（ここ 1 ～ 2 年）

3. **経営チーム** (1,000-1,400 ワード)
   - 3 ～ 4 人の幹部の各 300 ～ 400 ワードの経歴
   - 取締役会の構成とガバナンス
   - 内部者の持株
   - 経営実績評価

4. **製品とサービス** (700 ～ 1,000 ワード)
   - 詳細な製品ポートフォリオ
   - 主な特徴と機能
   - 製品の差別化
   - 対象顧客とユースケース
   - 価格モデルと一般的な取引規模

5. **顧客と市場開拓** (500 ～ 700 ワード)
   - 顧客セグメントとプロファイル
   - 流通チャネル
   - 販売戦略とサイクル
   - 主要なパートナーシップ
   - お客様の事例紹介

6. **業界の概要** (800 ～ 1,200 ワード)
   - 業界の定義と範囲
   - 市場規模と構造
   - 成長率（過去および予測）
   - 主要なトレンドと推進力
   - 規制環境
   - 業界の動向

7. **競争環境** (700～1,000 ワード)
   - 5 ～ 10 社の主要な競合他社の分析
   - 市場ポジショニングの枠組み
   - 会社の競争上の優位性
   - 競合上の脆弱性
   - 市場シェア分析

8. **市場機会** (500-700 ワード)
   - TAM のサイジングと方法論
   - 市場の成長予測
   - 自社のサービス可能な市場
   - 市場シェアの機会
   - 浸透戦略

9. **リスク評価** (600-900 ワード)
   - 企業固有のリスク (4-6)
   - 業界/市場リスク (3-4)
   - 財務リスク (2-3)
   - マクロ経済リスク (2-3)
   - 各リスク: 50 ～ 100 語の説明

**データ ソース セクション**
- 使用されたすべてのソースをリストする
- 日付とURLを含める
- ソースの種類ごとに整理する

<a id="quality-standards"></a>
## 品質基準

<a id="content-depth"></a>
### コンテンツの深さ
- 各セクションは最小単語数の目標を満たしている必要があります
- 分析は単なる説明的なものではなく、実質的なものである必要があります
- 具体的な例や定量的なデータを活用する
- 全体を通して出典を引用する
- 客観性とバランスを維持する

<a id="management-bios"></a>
### 経営経歴
- 3 ～ 4 人の主要幹部の場合、幹部あたり 300 ～ 400 ワード
- 含める必要があるもの: 現在の役割、これまでの経験、主な業績、学歴
- 実績と能力を評価するのに十分な詳細を提供する

<a id="competitive-analysis"></a>
### 競合分析
- 5 ～ 10 社の特定の競合他社を分析する必要がある
- 直接的および間接的な競合企業の両方を含める
- 主要な評価軸における相対的な位置を評価する
- 企業の競争上の利点と脆弱性を特定する
- 具体的なデータと例を使用する

<a id="risk-assessment"></a>
### リスク評価
- 4 つのカテゴリすべてにわたって 8 ～ 12 の異なるリスクを特定する必要がある
- 各リスクには 50 ～ 100 語の説明が必要です
- 可能な場合は影響を定量化する
- 緩和要因に注意してください
- 4 つのリスク カテゴリすべてをカバー

<a id="writing-quality"></a>
### 文章の品質
- プロフェッショナルで分析的なトーン
- 重要な洞察でリードする
- 具体的な例やデータを活用する
- 一般的なステートメントを避ける
- 全体を通して適切な引用を行う

<a id="success-criteria"></a>
## 成功基準

タスク 1 が正常に完了すると、以下が得られます。

1. 6,000～8,000 単語の目標を達成 (単語数を確認)
2. 9 つの必須セクションをすべて目標の単語数で含める
3. 単なる説明ではなく、実質的な分析を提供する
4. 具体的な例や定量的なデータを活用する
5. すべての情報源を適切に引用する
6. 読者が以下を理解できるようにする:
   - 会社は何をやっていて、どのようにしてお金を稼いでいるのか
   - 経営陣の質と実績
   - 会社の競争上の地位
   - 市場機会の規模
   - 考慮すべき主なリスク
