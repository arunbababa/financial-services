<a id="buyer-list"></a>
# 購入者リスト

<a id="workflow"></a>
## ワークフロー

<a id="step-1-understand-the-target"></a>
### ステップ 1: ターゲットを理解する

- 会社概要、分野、ビジネスモデル
- 収益、EBITDA、および成長プロファイル
- 主要な資産と機能 (IP、顧客関係、地理的拠点、チーム)
- 予想される評価範囲
- 売り手の好み（戦略的か財務的か、経営の継続性、スケジュール）

<a id="step-2-strategic-buyers"></a>
### ステップ 2: 戦略的バイヤー

カテゴリ全体で戦略的買収者を特定します。

**直接の競合他社**
- 同じ分野で市場シェアを獲得する企業
- 根拠: 収益の相乗効果、競合他社の排除、規模の拡大

**隣接するプレイヤー**
- ターゲット領域に進出する可能性のある隣接市場の企業
- 根拠: 製品の拡張、クロスセル、新規市場への参入

**垂直インテグレーター**
- 垂直統合できる顧客またはサプライヤー
- 理論的根拠: サプライチェーン管理、マージン確保、戦略的ロックイン

**プラットフォーム ビルダー**
- M&Aを通じてこの分野でプラットフォームを構築する大企業
- 理論的根拠: 既存事業を補完する小規模買収（タックイン）、能力ギャップを埋める

戦略的購入者ごとに、以下を評価します。

| 購入者 | セクター | 収益 | 戦略的適合 | 財務能力 | M&A実績 | 可能性 | 優先順位 |
|-------|--------|---------|--------------|-------------------|------------------|------------|----------|
| | | | 高/中/低 | | アクティブ/中程度/なし | | A/B/C |

<a id="step-3-financial-sponsors"></a>
### ステップ 3: 金融スポンサー

PE/金融の買い手を特定する:

**プラットフォーム投資家**
- この分野で新しいプラットフォームを探しているスポンサー
- 基準: ファンドの規模、重点セクター、取引規模の範囲

**アドオン購入者**
- ボルトオンでターゲットを獲得できる既存のポートフォリオ企業を持つスポンサー
- 特定のポートフォリオ企業とシナジーの理論的根拠を特定する

**成長資本**
- 初期段階または高成長のターゲット向け
- 少数持分か過半数持分かの選好

各スポンサーについて:

| スポンサー | 基金の規模 | セクターの焦点 | ポートフォリオの重複 | 最近の活動 | 優先順位 |
|---------|-----------|-------------|-------------------|-----------------|----------|
| | | | | | A/B/C |

<a id="step-4-prioritization"></a>
### ステップ 4: 優先順位付け

購入者リストを階層化します。

- **Tier 1 (5-10)**: 最も戦略的適合性が高く、実績のある買収者、明確な根拠 - まずはお問い合わせください
- **Tier 2 (10-15)**: 適合性は良いが、明らかではない - 第 2 波での接触
- **Tier 3 (10-20)**: 可能性はありますが、可能性は低くなります。プロセスの拡大が必要な場合はご連絡ください。

<a id="step-5-contact-mapping"></a>
### ステップ 5: 連絡先のマッピング

各 Tier 1 購入者に対して:
- 主要な意思決定者 (CEO、企業開発責任者、パートナー)
- 人間関係のステータス (既存の関係、面識のない相手への接触、紹介の必要性)
- 把握している選好や制約 (サイズ、地理、構造)
- ベストアプローチチャネル

<a id="step-6-output"></a>
### ステップ 6: 出力

- Excel ワークブック:
  - 「戦略的購入者」タブ (層ごとに並べ替え)
  - 財務スポンサー タブ (階層ごとに並べ替え)
  - Tier 1 の連絡先マッピング
  - 概要統計 (階層別、タイプ別の合計購入者数)
- エンゲージメント レターまたは提案に関する 1 ページのバイヤー ユニバースの概要

<a id="important-notes"></a>
## 重要な注意事項

- 量より質 — よく調査された30～40人のバイヤーの集中リストが200名のリストよりも優れています
- 最近の M&A 活動を調査する - この分野で取引を行ったばかりの買い手は、さらなるニーズに飢えているか、あるいは追加投資余力を使い切っているかのどちらかです
- 直接の競合他社との独占禁止法上の懸念を確認し、規制上の問題に直面する可能性のある企業にはフラグを立てます
- 金融スポンサー: ファンドのヴィンテージと展開ペースを確認してください。投資期間の終わりに近づいているファンドは、より意欲的である可能性があります。
- 含めたい購入者がいるか除外したい購入者がいるかどうかを常に販売者に尋ねます。
- プロセスの進行に応じてリストを更新します。フィードバックに基づいて購入者を階層間で移動します。
