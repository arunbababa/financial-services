<a id="process-letter"></a>
# プロセスレター

<a id="workflow"></a>
## ワークフロー

<a id="step-1-determine-letter-type"></a>
### ステップ 1: 書簡の種類を決定する

- **最初のプロセス レター**: プロセスと IOI 要件の概要を説明するティーザー/CIM とともに送信されます。
- **IOI 指示**: 第 1 ラウンドの買収関心表明（IOI）に対する特定の要件
- **第 2 ラウンド/最終入札書**: 精査後に拘束力のあるオファーを提出するための手順
- **経営会議への招待状**: 対面での経営プレゼンテーションの準備

<a id="step-2-initial-process-letter--ioi-instructions"></a>
### ステップ 2: 初期プロセスレター/IOI 指示

**ヘッダー:**
- 日付、取引コード名
- 「機密」
- 購入希望者宛

**セクション:**

1. **はじめに**: 機会と売り手の目的の簡単な概要
2. **プロセスの概要**: タイムライン、重要な日付、予想されるラウンド数
3. **IOI 要件**: 最初の関心表明に含める内容:
   - 提案される評価範囲（企業価値）
   - 対価フォーム（現金、株式、アーンアウト、ロールオーバー）
   - 資金源と確実性
   - 重要なデューデリジェンスの要件
   - クロージングまでの想定日程
   - あらゆる条件や不測の事態
   - 買い手の簡単な説明と戦略的根拠
4. **提出内容**：送付先、締切（日時）、フォーマット
5. **機密保持に関するリマインダー**: NDA、データ ルームへのアクセスへの言及
6. **連絡先情報**: 質問に対する銀行担当者の連絡先

<a id="step-3-final-bid--second-round-letter"></a>
### ステップ 3: 最終入札 / 第 2 ラウンドのレター

IOI 以外の追加要件:

1. **購入契約のマークアップ**: SPA/APA の草案を提供し、マークアップをリクエストします
2. **資金調達に関する詳細な約束**: 約束された資金調達レターが必要です
3. **残りのデリジェンス項目**: どのような確認的デリジェンスが期待されるかを指定します
4. **独占期間**: 独占期間の期間と条件
5. **規制分析**: 独占禁止法申請要件とスケジュール
6. **主要な人事条件**: 雇用契約、報酬、再投資する持分（ロールオーバー・エクイティ）
7. **拘束力と非拘束力**: この段階で何が拘束力であるかを明確にします
8. **評価基準**: 入札の評価方法 (価格、確実性、スピード、適合性)

<a id="step-4-management-meeting-invitation"></a>
### ステップ 4: 経営会議への招待

1. **ロジスティクス**: 日付、時刻、場所 (またはビデオリンク)、期間
2. **出席者**: 会社の誰が出席するか、バイヤーの誰が出席する必要があるか
3. **議題**: 典型的な経営陣のプレゼンテーションの議題 (概要、財務、運営、成長、Q&A)
4. **基本ルール**: 録音禁止、機密保持、質問形式
5. **資料**: 配布されるもの (プレゼンテーション資料、データ ルームへのアクセス)
6. **フォローアップ**: 会議後に追加の質問を提出するプロセス

<a id="step-5-output"></a>
### ステップ 5: 出力

- プロフェッショナルなレターフォーマットを備えた Word 文書 (.docx)
- 自社レターヘッドのプレースホルダー
- クライアント確認用の変更履歴付き版

<a id="important-notes"></a>
## 重要な注意事項

- プロセスレターは取引全体の雰囲気を決定します - 明確で、プロフェッショナルで、組織的である必要があります
- 期限はしっかりとしたものにする必要がありますが、妥当なものでなければなりません。通常、IOI の場合は 2 ～ 3 週間、最終入札の場合は 3 ～ 4 週間です。
- 常に評価基準を含めてください。購入者は自分がどのように評価されるかを知りたいと考えています。
- 書簡内の表明または約束に関して法務担当者と調整する
- クライアントは送信前に内容を確認して承認する必要があります。文調や条件を調整する必要がある場合があります。
- 各手紙を誰がいつ受け取ったかを記録し、これがプロセス追跡になります。
