<a id="financial-data-pack-builder"></a>
# 財務データ パック ビルダー

プライベート エクイティ、投資銀行業務、資産管理向けに、専門的な標準化された財務データ パックを構築します。 CIM、募集・売却説明資料、SEC提出書類、Web検索、MCPサーバーから得た財務データを、投資委員会のレビューに適した整ったExcelワークブックへ変換します。

**重要:** このワークフロー全体にわたるすべての Excel ファイルの作成と操作には、xlsx スキルを使用します。

<a id="critical-success-factors"></a>
## 重要な成功要因

すべてのデータ パックはこれらの標準を達成する必要があります。いずれかの点で失敗すると、成果物は使用できなくなります。

<a id="1-data-accuracy-zero-tolerance-for-errors"></a>
### 1. データの精度 (エラーに対するゼロトレランス)
- ページ参照を使用して、すべての数値をソース文書まで追跡します
- 数式ベースの計算のみを使用します (ハードコーディングされた値は使用しません)
- 小計と合計をクロスチェックして内部の一貫性を確認する
- 貸借対照表の残高を確認します: 資産 = 負債 + 資本
- キャッシュフローと貸借対照表の変化の関係を確認する

<a id="2-essential-rules"></a>
### 2. 重要なルール

**ルール 1: 財務データ (お金の計測) → $ を使用した通貨形式**
トリガー: 収益、売上、収入、EBITDA、利益、損失、原価、経費、現金、負債、資産、負債、資本、設備投資
形式: $#,##0.0 (百万の場合)、$#,##0 (千の場合)
マイナス: $(123.0) NOT -$123

**ルール 2: 事業データ (物を数える) → 数値形式、NO $**
トリガー: ユニット、店舗、場所、従業員、顧客、平方フィート、物件、人数
形式: #,##0 (カンマ付き)
マイナス: (123) 表の残りの部分と一致

**ルール 3: パーセンテージ (レートと比率) → パーセンテージ形式**
トリガー: マージン、成長率、レート、パーセンテージ、利回り、リターン、使用率、占有率
形式: 小数点第 1 位は 0.0%
表示: 15.0% NOT 0.15

**ルール 4: 年 → カンマの挿入を防ぐためのテキスト形式**
形式: テキストまたは 2,024 を防ぐためのカスタム
表示: 2020、2021、2022、2023A、2024E

**ルール 5: コンテキストが混在する場合、各メトリックは独自の適切な形式になります**
例:
```
Segment Analysis, 2022, 2023, 2024
Retail Revenue, $50.0, $55.0, $60.0
  Stores, 100, 110, 120
  Revenue per Store, $0.5, $0.5, $0.5
```
収益と店舗ごとの指標には $ が使用され、店舗数には数値形式が使用されます。

**ルール 6: すべての計算に式を使用する → 計算値をハードコードしないでください**
すべての小計、合計、比率、および派生メトリックは、ハードコードされた値ではなく、数式ベースである必要があります。これにより精度が保証され、動的な更新が可能になります。

<a id="3-professional-presentation-standards"></a>
### 3. プロフェッショナルなプレゼンテーションの基準

**フォーマット標準:**

**配色 - 2 つのレイヤー:**

**レイヤー 1: フォントの色 (xlsx スキルから必須)**
- **青色のテキスト (RGB: 0,0,255)**: すべてのハードコードされた入力 (履歴データ、仮定)、通常のテキストではありません
- **黒色のテキスト (RGB: 0,0,0)**: すべての式と計算
- **緑色のテキスト (RGB: 0,128,0)**: 他のシートへのリンク

**レイヤー 2: 塗りつぶしの色 (プレゼンテーションを強化するためのオプション)**
- 塗りつぶしの色はオプションであり、ユーザーが要求した場合、またはプレゼンテーションを強化する場合にのみ適用する必要があります。
- ユーザーが色や専門的な書式設定を要求した場合は、次の標準スキームを使用します。
  - **セクション ヘッダー**: 濃い青色 (RGB: 68,114,196) の背景に白い文字
  - **サブヘッダー/列ヘッダー**: 水色 (RGB: 217,225,242) の背景に黒のテキスト
  - **入力セル**: ライトグリーン/クリーム (RGB: 226,239,218) の背景に青色のテキスト
  - **計算セル**: 白の背景に黒のテキスト
- 指定されている場合、ユーザーはカスタム ブランド カラーで上書きできます

**レイヤーの連携方法 (塗りつぶし色が使用されている場合):**
- 入力セル: 青色のテキスト + 薄緑色の塗りつぶし = 「ユーザーが入力したデータ」
- 数式セル：黒文字＋白背景＝「計算値」
- シートリンク：緑色の文字＋背景白＝「別タブからの参照」

**フォントの色でそれが何であるかがわかります。塗りつぶしの色によって、それがどこにあるかがわかります (使用されている場合)。**

**重要:** xlsx スキルのフォントの色は必須です。塗りつぶしの色はオプションです。ユーザーが拡張された書式設定または色を要求しない限り、デフォルトは白/塗りつぶしなしです。

**常に適用してください:**
- 太字のヘッダー、左揃え
- 数値を右揃え
- サブ項目の 2 スペースのインデント
- 小計の上に単一の下線を引く
- 最終合計の下に二重下線を引く
- 行/列ヘッダーのペインをフリーズする
- 最小限の境界線 (構造上必要な場合のみ)
- 一貫したフォント (通常は Calibri または Arial 11pt)

**次のものは決して含めないでください**
- すべてのセルの周囲の境界線
- 複数のフォントまたはフォント サイズ
- 特にリクエストがない限り、チャート
- 過剰な書式設定や装飾

<a id="structural-consistency"></a>
## 構造の一貫性
特に指示がない限り、標準の 8 タブ構造を使用します。
1. エグゼクティブサマリー
2. 過去の財務（損益計算書）
3. 貸借対照表
4. キャッシュフロー計算書
5. 事業指標
6. 物件/セグメントの業績 (該当する場合)
7. 市場分析
8. 投資ハイライト

<a id="tab-1-executive-summary"></a>
### タブ 1: 概要
目的: 多忙な経営者向けの 1 ページの概要

内容：
- 会社概要（ビジネスモデルについて2～3文）
- 主要な投資のハイライト (3 ～ 5 つの箇条書き)
- 財務スナップショット表 (過去 3 年間の収益、EBITDA、成長率 + 予測)
- 該当する場合、取引の概要
- 主要な指標を目立つように表示

フォーマット: すっきりとした太字のヘッダー、最小限の装飾、重要な数字を強調

<a id="tab-2-historical-financials-income-statement"></a>
### タブ 2: 過去の財務状況 (損益計算書)
目的: 完全な損益履歴

内容：
- セグメント/製品ライン別の収益内訳
- 売上原価 / 収益原価
- 売上総利益および売上総利益率 %
- 営業費用詳細（S&M、R&D、G&A）
- EBITDAおよび調整後EBITDA
- ライン以下項目（D&A、利息、税金）
- 当期純利益

形式:
- 列としての年（テキスト形式：2020、2021、2022）
- 百万ドルまたは千ドル (上部に単位を明確に指定)
- すべての財務データの会計フォーマット
- 小計の上に 1 本の下線、純利益の下に 2 つの下線
- すべての数値を右揃えにする

<a id="tab-3-balance-sheet"></a>
### タブ 3: 貸借対照表
目的：期末財政状態

内容：
- 流動資産（現金、AR、在庫、前払い、その他）
- 長期資産（PP&E、無形資産、のれん、その他）
- 流動負債（AP、未払費用、1年以内に返済予定の負債、その他）
- 固定負債（長期借入金、繰延税金等）
- 株主資本（普通株式、利益剰余金、その他）

形式:
- 式を確認します: 資産 = 負債 + 資本
- 一貫した日付ラベル付け
- 運転資本の計算を含む
- 大小計の上には 1 つの下線、最終合計には 2 つの下線

<a id="tab-4-cash-flow-statement"></a>
### タブ 4: キャッシュ フロー計算書
目的: 現金の生成と使用の分析

内容：
- 営業キャッシュフロー（間接法推奨）
- 投資キャッシュ フロー (設備投資、買収、資産売却)
- 財務キャッシュフロー（借入金の発行・返済、自己資本、配当金）
- 現金の純変動
- 期首および期末の現金残高

形式:
- 可能な場合は損益計算書と貸借対照表へのリンク
- 純利益と営業キャッシュフローの調整を表示
- 現金の使用（流出）と資金源（流入）の明確なラベル付け

<a id="tab-5-operating-metrics"></a>
### タブ 5: 事業指標
目的: 非財務 KPI と事業データ

内容 (業界に応じて):
- 販売台数、顧客数、所在地
- 生産性指標 (従業員あたり、店舗あたり、ユニットあたりの収益)
- 容量使用率
- 市場シェア
- 顧客維持率/解約率
- 業界固有のKPI

**フォーマットに関する重要な注意:**
事業指標にはドル記号はありません。これらは数量であり、通貨ではありません。

形式:
- 明確な単位の指定 (顧客、従業員、店舗、平方フィートなど)
- カンマ付きの整数: 1,250 NOT $1,250
- 比率にはパーセント表示: 95.0%
- 数値を右揃えにする

<a id="tab-6-propertysegment-performance-if-applicable"></a>
### タブ 6: プロパティ/セグメントのパフォーマンス (該当する場合)
目的: ビジネスユニット、プロパティ、またはセグメントごとの詳細な内訳

内容：
- セグメント別売上高と利益率
- 場所/製品ごとの主要な指標
- セグメント別KPI
- 性能比較分析

形式: 収益/EBITDA の財務タブと一致し、事業指標の数値形式

<a id="tab-7-market-analysis"></a>
### タブ 7: 市場分析
目的: 業界の背景と競争上の位置づけ

内容：
- 市場規模と成長傾向
- 競争環境の概要
- 市場シェア分析
- 業界のベンチマークと競合他社の比較
- 規制環境（該当する場合）

形式: 説明文と表の組み合わせ、市場データのソースを引用

<a id="tab-8-investment-highlights"></a>
### タブ 8: 投資のハイライト
目的: 投資に関する主要な論点の要約

内容：
- 競争力の詳細な記述
- 成長の機会と戦略的取り組み
- リスク要因と緩和戦略
- 経営評価と実績
- 投資仮説の概要

形式: 明確なヘッダー、箇条書き、簡潔な段落

<a id="step-by-step-workflow"></a>
## 段階的なワークフロー

<a id="phase-1-document-processing-and-data-extraction"></a>
### フェーズ 1: ドキュメントの処理とデータ抽出

**ステップ 1.1: ソース データを分析する**
- ソース資料へのアクセス: アップロードされた文書、公的書類の Web 検索、または MCP サーバー データ
- データ構造を確認し、主要なセクションを特定する
- 財務諸表を検索します (通常は 3 ～ 5 年分の過去のもの)
- 経営上の予測が含まれている場合はそれを特定する
- 決算日を記す
- データ品質の問題があればすぐに報告してください

**ステップ 1.2: 財務諸表の抽出**
- 過去の損益計算書データの検索
- 貸借対照表のスナップショットの抽出 (年度末または四半期末)
- キャッシュフロー計算書を探す
- 可能な場合は経営予測を抽出する
- トレーサビリティのためにすべてのページ参照を記録します

**ステップ 1.3: 事業指標の抽出**
- 業界に関連する非財務 KPI を特定する
- ユニットエコノミクスデータを取得する
- 顧客/場所/容量データの抽出
- 成長指標と傾向を文書化する

**ステップ 1.4: 市場および業界データを抽出する**
- 競合上のポジショニング情報
- 市場規模と成長率
- 業界ベンチマークデータ
- ピア比較情報

**ステップ 1.5: キーのコンテキストをメモします**
- 取引の構造と根拠
- 経営陣の背景
- ソース資料からの投資ハイライト
- リスク要因と考慮事項
- データのギャップまたは不一致

<a id="phase-2-data-normalization-and-standardization"></a>
### フェーズ 2: データの正規化と標準化

**ステップ 2.1: 会計表示を正規化する**
- すべての年にわたって一貫した勘定科目名を確保する
- 収益認識処理の標準化
- 1 回限りの料金を特定して文書化する
- 必要に応じて「調整後EBITDA」調整を作成します
- 会計ポリシーの変更に注意してください

**ステップ 2.2: フォーマット検出ロジックを適用する**
データ ポイントごとに、完全なコンテキストに基づいて形式を決定します。
- タブ名、テーブルタイトル、列ヘッダー、行ラベルを読み取ります。
- 重要なルールを適用します (上記を参照)
- 不明な場合は、元のソース文書を調べてください
- デフォルトではよりクリーンな書式設定になります (少ないほど良い)

**ステップ 2.3: 正規化調整を特定する**
文書に対する一般的な調整:
- リストラ費用（本当に非経常の場合は追加）
- 株式ベースの報酬（業界標準に従って追加）
- 取得関連費用（加算、金額指定）
- 法的和解または訴訟費用（再発リスクの評価）
- 資産売却または減損（経営成績から除く）
- 関連当事者調整（市場レートへの平準化）
注: ソースの引用形式はデータ ソースによって異なります (ドキュメントのページ番号、Web ソースの URL、MCP データのサーバー参照)。

**ステップ 2.4: 調整スケジュールの作成**
すべての正規化について:
- 調整内容とその理由を文書化する
- 出典の引用 (文書のページ番号、URL、またはデータ ソース参照)
- ドルへの影響を年ごとに定量化する
- 再発リスクの評価
- 報告値から調整値までの計算を表示

**ステップ 2.5: データの整合性を確認する**
- 数式を使用して小計の合計を正しく確認する
- 貸借対照表の残高を確認する
- キャッシュフローと貸借対照表の変化の関係を確認する
- 一貫性があるかどうかタブ全体で数値をクロスチェックする
- 不一致がある場合は調査のためにフラグを立てます

<a id="phase-3-build-excel-workbook"></a>
### フェーズ 3: Excel ワークブックを構築する

**重要: すべての Excel ファイル操作には xlsx スキルを使用してください。続行する前に、xlsx スキルのドキュメントをお読みください。**

**ステップ 3.1: 標準化されたタブ構造を作成する**
タブを含むワークブックを作成します。
- エグゼクティブサマリー
- 過去の財務状況
- 貸借対照表
- キャッシュフロー
- 事業指標
- プロパティのパフォーマンス (該当する場合)
- 市場分析
- 投資ハイライト

**ステップ 3.2: 適切な書式設定で各タブを作成します**
書式設定ルールを体系的に適用します。
- ヘッダー: 太字、左揃え、11pt フォント
- 財務データ: 通貨形式 $#,##0.0 (百万ドル)
- 事業データ: 数値形式 #,##0 ($ なし)
- パーセンテージ: 0.0% 形式
- 年: カンマの挿入を防ぐテキスト形式
- マイナス: 括弧付きの会計形式を使用します。
- 下線: 小計の上に 1 つ、合計の下に 2 つ

**ステップ 3.3: 計算式を挿入します**
- すべての小計と合計は数式に基づいている必要があります
- 必要に応じて貸借対照表を損益計算書にリンクする
- キャッシュフローを損益計算書と貸借対照表の両方にリンクする
- 検証用のタブ間参照を作成する
- 計算値をハードコーディングしないでください

### 行参照追跡 - このパターンをコピーします

**データを書き込むときに行番号を保存し、数式で参照します:**

```python
# ✅ CORRECT - Track row numbers as you write
revenue_row = row
write_data_row(ws, row, "Revenue", revenue_values)
row += 1

ebitda_row = row
write_data_row(ws, row, "EBITDA", ebitda_values)
row += 1

# Use stored row numbers in formulas
margin_row = row
for col in year_columns:
    cell = ws.cell(row=margin_row, column=col)
    cell.value = f"={get_column_letter(col)}{ebitda_row}/{get_column_letter(col)}{revenue_row}"
```

**複雑なモデルの場合は、辞書を使用してください:**

```python
row_refs = {
    'revenue': 5,
    'cogs': 6,
    'gross_profit': 7,
    'ebitda': 12
}

# Later in formulas
margin_formula = f"=B{row_refs['ebitda']}/B{row_refs['revenue']}"
```

</correct_patterns>

<common_mistakes>

<a id="wrong-hardcoded-row-offsets"></a>
### 間違い: ハードコードされた行オフセット

**相対オフセットは使用しないでください。テーブル構造が変更されると壊れます。**

```python
# ❌ WRONG - Fragile offset-based references
formula = f"=B{row-15}/B{row-19}"  # What is row-15? What is row-19?

# ❌ WRONG - Magic numbers
formula = f"=B{current_row-10}*C{current_row-20}"
```

**これが失敗する理由:**
- 行を追加/削除するとサイレントに中断される
- コードを読んで正確性を検証することはできません
- 配布された Excel ファイルにデバッグの悪夢が作成されます

</common_mistakes>

- 適切な列幅を設定します (通常は 12 ～ 15 文字)

### フェーズ 4: シナリオの構築 (予測が含まれる場合)

**経営陣ケース:**
ソース資料に記載されている会社の予測を示します。
- 経営上の前提条件をすべて抽出する
- 成長率、利益率の拡大、資本要件を文書化する
- 主要な要因と感受性をメモする
- 懐疑的な見方が必要な「ホッケースティック」のような急な転換にフラグを立てます
- 明確なラベルを付けて「経営陣ケース」として提示

**基本ケース (リスク調整後):**
企業固有のリスク要因に基づいて、経営予測に保守的な調整を適用します。
- 実行リスクと過去の予測精度を反映した収益成長ヘアカットを適用する
- 業界ベンチマークと営業レバレッジに基づいた適度な利益拡大の想定
- 成長に依存する場合は設備投資の想定を増やす
- 運転資本要件が過小評価されている場合は追加する

**マイナス面のケース (オプションですが、LBO 分析には推奨):**

- 景気後退リスクや競争圧力を反映したモデル収益の減少
- ストレス（数量減少による固定費負担率の悪化、価格設定圧力）下でのマージン圧縮を想定する
- 約款の遵守と流動性をテストする
- 下値保護を評価する
- ストレステスト中の主要なリスクを文書化する

**シナリオの文書要件:**
以下を示す仮定スケジュールを作成します。
- シナリオ別の主要な前提条件 (収益の伸び、利益率、設備投資の割合)
- 各調整の理論的根拠
- 主要変数の感度分析
- 過去の予測精度 (利用可能な場合)
- 業界ベンチマークとの比較

<a id="normalization-patterns"></a>
## 正規化パターン

<a id="common-adjustments-to-ebitda"></a>
### EBITDAの一般的な調整

**1.リストラ費用**
- 本当に一過性の場合は足し戻します（施設閉鎖、一時的な退職金）。
- 会社が毎年リストラする場合は足し戻さないでください
- 費用の具体的内容と、再発しないと判断する根拠を文書化する
- 例: 「2023 年の再編: 300 万ドルの施設閉鎖、資料に記載、1 回限りのイベント」

**2.株式報酬**
- 業界標準: プライベートエクイティ分析では足し戻す
- 現金以外の営業経費として扱う
- すべての期間にわたって一貫性を保つ
- 異常に高い場合、または 一回限りの報酬付与が含まれている場合は注意してください

**3.買収関連費用**
- 取引手数料や統合コストを足し戻す
- 種類ごとに具体的な金額を文書化する
- 継続的な統合投資は足し戻さないでください
- 各調整のソースを引用する

**4.法的和解と訴訟**
- 本当に単発の事象なら足し戻す
- 再発リスクを評価する (1 つの和解と訴訟のパターン)
- 和解の内容を文書化する
- これが通常の業務であるかどうかを検討してください

**5.資産の売却または減損**
- 営業EBITDAから資産売却損益を除く
- 本当に非経常的な場合は減損費用を削除する
- どの資産が売却/減損されたのか、そしてその理由を文書化する
- 資産が営業利益を生み出した場合は収益を調整する

**6.関連当事者の調整**
- 市場水準を上回る関連当事者への費用（賃料・経営管理料）を正常化する
- サポート文書を使用して市場レートに調整する
- 会社の経費に計上された個人的な支出を除く
- 市場レートの比較を文書化する

<a id="conservative-vs-aggressive-normalization"></a>
### 保守的な正規化と積極的な正規化

**経営陣ケース:**
- 管理者が提案したすべての調整を含める
- 会社の「非経常的」の定義を受け入れる
- より積極的なEBITDA調整
- 経営者の考え方を理解するために活用

**基本ケース (投資決定に推奨):**
- 明らかに非経常的な項目のみ
- 定期的な「1 回限り」の料金に対してより厳密な精査を適用する
- 投機的な調整を除外する
- より保守的で、投資委員会に根拠を説明できる

## 業界特有の適応

<a id="technologysaas"></a>
### テクノロジー/SaaS
取得すべき主要な指標:

- コホート別の顧客数
- CAC（顧客獲得コスト）とLTV（生涯価値）

- 在庫回転数
- 製品ライン別の粗利益率
- 受注残

形式に関するメモ: 単位、容量は数値 ($ なし)、使用率は %、収益/コストは通貨です

<a id="real-estatehospitality"></a>
### 不動産・接客業

- 物件/部屋/面積

- NOI (純営業利益) - 通貨形式
- キャップレート%
- FF&Eリザーブ

形式に関するメモ: 部屋数/平方フィートは数値、占有率は %、ADR/RevPAR は通貨です

<a id="healthcareservices"></a>
### ヘルスケア/サービス

- 所在地・設備
- プロバイダー/従業員
- 患者数/訪問数 (ボリューム指標)
- 訪問あたりの収益 - 通貨
- 支払者の割合 %
- 既存店成長率（%）

注記の形式: 場所/訪問は数値、訪問あたりの収益は通貨、料金は %
