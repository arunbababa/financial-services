# 取引トラッカー

<a id="workflow"></a>
## ワークフロー

<a id="step-1-deal-setup"></a>
### ステップ 1: 取引の設定

取引ごとに、以下をキャプチャします。
- **取引名 / コード名**: プロジェクト [名前]
- **クライアント**: 販売者または購入者の名前
- **取引タイプ**: セルサイド、バイサイド、ファイナンス、リストラ
- **役割**: 主任顧問、共同顧問、フェアネス・オピニオン
- **取引規模**: 期待される企業価値
- **ステージ**: 委任前 → エンゲージメント → マーケティング → IOI → デューデリジェンス → 最終入札 → 契約締結 → クロージング
- **チーム**: MD、VP、アソシエイト、アナリストが割り当てられています
- **重要な日付**: 契約日、CIM 配布、IOI 期限、経営会議、最終入札期限、目標クロージング日

<a id="step-4-weekly-deal-review"></a>
### ステップ 4: 毎週の取引レビュー

毎週のチーム会議の概要を生成します。

**アクティブな取引ごと:**
1. 1 行のステータス更新
2. 今週の主な展開
3. 今後のマイルストーン (今後 2 週間)
4. 阻害要因またはリスク
5. 来週のアクションアイテム

**パイプラインの概要:**
- ステージ別のアクティブな取引の合計
- リスクにさらされている取引（マイルストーンの逸失、プロセスの停滞）
- 新規の受託案件／提案がパイプラインにあります
- 今四半期のクロージング見込み

<a id="step-5-output"></a>
### ステップ 5: 出力

- Excel ワークブック:
  - パイプラインの概要 (すべての取引、それぞれ 1 行)
  - 取引ごとのマイルストーン トラッカー タブ
  - アクションアイテムマスターリスト
  - 週次レビューの概要
- オプション: 電子メール/Slack 配布用のマークダウンの概要

<a id="important-notes"></a>
## 重要な注意事項

- トラッカーは少なくとも毎週更新します。トラッカーが古い場合は、トラッカーがないよりも悪いです。
- マイルストーンが遅れている取引にフラグを立てます - 早期の警告が予期せぬ事態を防ぎます
- 所有者と期限のないアクションアイテムは完了しません - 具体的にしてください
- パイプライン ビューには、取引の段階、規模、可能性が表示され、収益予測に役立ちます。
- 買い手/投資家のフィードバックをメモしておきます — フィードバックのパターンから戦略の調整がわかります
- 完了／中止した案件を個別にアーカイブします - アクティブなビューをクリーンな状態に保ちます
