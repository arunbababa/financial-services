<a id="teaser"></a>
# ティーザー

<a id="workflow"></a>
## ワークフロー

<a id="step-1-gather-inputs"></a>
### ステップ 1: 入力を収集する

- 会社概要（何をしているのか、どのようにしてお金を稼ぐのか）
- 分野・産業
- 主要な財務指標: 収益、EBITDA、成長率、利益率
- 地理的フットプリント
- 主要なセールス ポイント (3 ～ 5 つのハイライト)
- 何を匿名化するのか、何を開示するのか
- 対象となる購入者層 (戦略的、財務的、またはその両方)

<a id="step-2-teaser-structure"></a>
### ステップ 2: ティーザーの構造

専門的にフォーマットされた 1 ページ:

**ヘッダー**
- 取引コード名 (例: 「プロジェクト [名前]」)
- セクター記述子 (例: 「大手の専門産業サービス プラットフォーム」)
- 「機密情報 — ディスカッション目的のみ」

**会社概要** (2～3 文)
- 会社名は明かさないが何をしているのか
- 市場での地位 (例: 「... の大手プロバイダー」、「... のトップ 3 プレーヤー」)
- 地理 (都市固有ではなく地域レベル)

**投資のハイライト** (4 ～ 6 の箇条書き)
- 市場のリーダーシップ / ポジショニング
- 収益の質（継続収益の比率、維持率、多様化）
- 成長プロフィールと軌跡
- マージンプロファイルと拡大の機会
- 経営陣の強み
- 戦略的価値 / 相乗効果の可能性

**財務概要** (表または主要指標)

| メトリック | 値 |
|--------|-------|
| 収益 | $XXM |
| 収益の増加 | XX% CAGR |
| EBITDA | $XXM |
| EBITDAマージン | XX% |
| 従業員 | XXX |

**取引概要** (2～3 文)
- 提供内容 (100% 売却、過半数株式、成長資本)
- 示唆的なタイムライン
- 興味表明のための連絡先情報

<a id="step-3-anonymization-check"></a>
### ステップ 3: 匿名化チェック

ティーザーで誤って会社を特定しないようにしてください。
- 会社名、ブランド名、製品名はありません
- 特定の都市なし (使用地域: 「米国南東部」、「中西部」)
- 指名された顧客やパートナーはいない
- 特徴的すぎて特定につながる場合は従業員数を載せない
- セクターが小さい場合は、正確な数字ではなく収益範囲
- ロゴ、スクリーンショット、または識別可能な画像は使用しないでください

<a id="step-4-output"></a>
### ステップ 4: 出力

- Word 文書 (.docx) — 1 ページ、きれいな書式設定
- 配布用PDF版
- オプションの PowerPoint バージョン (単一スライド)

<a id="important-notes"></a>
## 重要な注意事項

- ティーザーの仕事は興味を引くことであり、取引を成立させることではありません。タイトで説得力のある内容を保つようにしてください。
- Less is more — 優れたティーザーは、購入者が詳細を知るために NDA に署名したくなるようにします。
- 意欲的かつ正確な言葉を使用します。真実であれば、「一流」、「差別化」、「高成長」でも問題ありません。
- 真剣な購入者を認定するのに十分な財務詳細を含めますが、買収意思の乏しい相手が時間を無駄にするほどではありません
- 配布前に必ずクライアントと法的レビューを受けてください
- 誰がティーザーを受け取ったのかを追跡します。これはプロセスのアウトリーチログになります。
