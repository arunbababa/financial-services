<a id="clean-data"></a>
# クリーンデータ

アクティブなシートまたは指定した範囲内の乱雑なデータをクリーンアップします。

<a id="environment"></a>
## 環境

- **Excel 内で実行している場合 (Office アドイン / Office JS):** Office JS を直接使用します (`Excel.run(async (context) => {...})`)。 `range.values` 経由で読み取り、`range.formulas = [["=TRIM(A2)"]]` 経由でヘルパー列数式を書き込みます。インプレースとヘルパー列の決定は引き続き適用されます。
- **スタンドアロンの .xlsx ファイルを操作する場合:** Python/openpyxl を使用します。

<a id="workflow"></a>
## ワークフロー

<a id="step-1-scope"></a>
### ステップ 1: 範囲

- 範囲が指定されている場合 (例: `A1:F200`)、それを使用します。
- それ以外の場合は、アクティブなシートの使用範囲全体を使用します。
- 各列のプロファイリング: 主要なタイプ (テキスト / 数値 / 日付) を検出し、外れ値を特定します。

<a id="step-2-detect-issues"></a>
### ステップ 2: 問題を検出する

| 問題 | 何を探すべきか |
|---|---|
| 空白 | 先頭/末尾のスペース、ダブルスペース |
| ケーシング | カテゴリ列の大文字と小文字が一貫していない (`usa` / `USA` / `Usa`) |
| テキストとしての数値 | テキストとして保存された数値。数値セルに紛れ込んだ `$`、`,`、`%` |
| 日付 | 同じ列内の形式が混在している (`3/8/26`、`2026-03-08`、`March 8 2026`) |
| 重複 | 完全に重複する行とほぼ重複する行 (大文字と小文字と空白の違い) |
| ブランク | それ以外の値が設定されている列の空のセル |
| 混合型 | 98% が数値であるが、テキスト エントリが 3 つある列 |
| エンコーディング | mojibake (`Ã©`、`â€™`)、非印刷文字 |
| エラー | `#REF!`, `#N/A`, `#VALUE!`, `#DIV/0!` |

<a id="step-4-apply"></a>
### ステップ 4: 適用する

- **ハードコーディングされたクリーンアップされた値よりも式を優先します** — クリーンアップされた出力が式として表現できる場合 (例: `=TRIM(A2)`、`=VALUE(SUBSTITUTE(B2,"$",""))`、`=UPPER(C2)`、`=DATEVALUE(D2)`)、Python で結果を計算して元の値を上書きするのではなく、隣接するヘルパー列に式を記述します。これにより、変換の透明性と監査可能性が維持されます。
- ユーザーが明示的に要求した場合、または意味のある同等の式が存在しない場合にのみ、計算された値でその場で上書きします (例: エンコード/文字化けの修復)
- 破壊的な操作 (重複の削除、空白セルの補完、オリジナルの上書き) については、最初にユーザーに確認してください。
- 各カテゴリの修正 (空白→大文字と小文字の区別→数値変換→日付→重複排除) の後、変更内容のサンプルをユーザーに表示し、次のカテゴリに移動する前に確認を得ます。
- 変更前/変更後の概要を報告する
