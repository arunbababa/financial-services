# フォーマット標準のリファレンス

| 要素 | フォーマット |
|---------|--------|
| ハードコーディングされた入力 | 青色のフォント |
| 数式 | 黒のフォント |
| 他のシートへのリンク | 緑色のフォント |
| セルをチェックする | エラーの場合は赤、バランスが取れている場合は緑 |
| 負の値 | マイナス記号ではなく括弧 |
| 通貨 | 大きな数字には小数点以下なし、1株当たりには小数点以下2桁 |
| パーセンテージ | 小数点第1位 |
| ヘッダー | 太字の下枠 |
| 単位行 | ヘッダーの下に単位行を含めます ($ millions、% など)。 |

<a id="visual-separation-guidelines"></a>
## 視覚的な分離ガイドライン

- 過去の列と予測された列の間の細い垂直境界線
- セクション合計の後の太い下枠 (例: 総資産)
- 小計の下枠は 1 つだけ
- 総計の二重下枠

<a id="balance-sheet-check-row-formatting"></a>
## 貸借対照表チェック行のフォーマット

貸借対照表のチェック行 (負債合計と資本の下) では、ゼロ以外の値を赤色で表示する条件付き数値書式設定が使用されています。貸借対照表のバランスが正しく取れている場合 (チェック = 0)、値は黒または標準の書式で表示されます。

| 値のチェック | フォントの色 |
|-------------|------------|
| = 0 (バランス) | 黒（標準） |
| ≠ 0 (エラー) | 赤 |

**実装:** カスタム数値形式 `[Red][<>0]0.00;[Red][<>0](0.00);0.00` を適用するか、ルール「セル値 ≠ 0」→赤色フォントで Excel 条件付き書式設定を使用します。

<a id="margin-row-formatting"></a>
## 利益率行の書式設定

| 要素 | フォーマット |
|---------|--------|
| 利益率（%） 行 | インデント、斜体、小数点以下 1 桁 |
| 前向きな傾向 | 特別な書式設定なし (または微妙な緑色) |
| マイナス傾向 | レビュー用フラグ (微妙な黄色) |
| 同業他社の平均を下回る | 議論のためにハイライトを検討する |

<a id="credit-metric-formatting"></a>
## クレジットメトリックのフォーマット

| 要素 | フォーマット |
|---------|--------|
| レバレッジ倍率 | 「x」接尾辞が付いた 小数点以下1桁 (例: 2.5x) |
| パーセンテージ | 「%」接尾辞が付いた 小数点以下1桁 |
| 純負債がマイナス | 括弧は純キャッシュポジションを示します |
| セクションヘッダー | 太字の「クレジットメトリクス」 |
| 区切り線 | クレジット指標セクションの上の細い境界線 |

<a id="credit-metric-threshold-colors"></a>
## クレジット メトリックのしきい値の色

| メトリック | 緑 | 黄色 | 赤 |
|--------|-------|--------|-----|
| 負債総額 / EBITDA | < 2.5x | 2.5x-4.0x | > 4.0x |
| 純負債/EBITDA | < 2.0x | 2.0x-3.5x | > 3.5x |
| インタレスト・カバレッジ | > 4.0x | 2.5x-4.0x | < 2.5x |
| 負債／総資本 | < 40% | 40%-60% | > 60% |
| 流動比率 | > 1.5x | 1.0x-1.5x | < 1.0x |
| 当座比率 | > 1.0x | 0.75x-1.0x | < 0.75x |

<a id="conditional-formatting-for-checks-tab"></a>
## 「チェック」タブの条件付き書式設定

- セルに合格インジケーターが含まれている → 緑色で塗りつぶされる
- セルに失敗インジケーターが含まれている → 赤で塗りつぶされる
- セルに警告が含まれている → 黄色で塗りつぶされる
- 差分セル = 0 → 薄緑色塗りつぶし
- 差分セル ≠ 0 → 薄赤塗りつぶし

<a id="margin-reasonability-flags"></a>
## マージン合理性フラグ

- 粗利益率 < 0% → エラー: 原価計算を確認してください
- 売上総利益率 > 80% → 警告: 収益/COGS を確認してください
- EBITDAマージン < 0% → FLAG: 営業損失
- EBITDA マージン > 50% → 警告: 異常に高い
- 純利益率 < 0% → FLAG: 純損失 (成長段階では許容される可能性があります)
- 純利益率 > 売上総利益率 → エラー: 計算式の問題
