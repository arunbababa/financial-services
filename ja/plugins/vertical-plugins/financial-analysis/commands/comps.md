<a id="comparable-company-analysis-command"></a>
# 類似会社分析コマンド

営業指標、評価倍率、統計的ベンチマークを使用して、機関レベルの比較可能な企業分析を構築します。

<a id="workflow"></a>
## ワークフロー

<a id="step-1-gather-company-information"></a>
### ステップ 1: 会社情報を収集する

会社名またはティッカーが提供されている場合は、それを使用します。それ以外の場合は次のように尋ねてください。
- 「どの企業を分析したいですか？」

<a id="step-2-load-comps-analysis-skill"></a>
### ステップ 2: ロードコンプ分析スキル

`skill: "comps-analysis"` を使用して分析を構築します。

1. **分析の目的を明確にする**:
   - 「重要な質問は何ですか?」 （バリュエーション、効率性、成長性の比較）
   - 「観客は誰ですか？」 (IC、取締役会、クイックリファレンス)
   - 「ご希望のフォーマットやテンプレートはありますか？」

2. **同業グループを特定** (同等の企業 4 ～ 6 社):
   - 同様のビジネスモデル
   - 同様の規模/時価総額範囲
   - 同じ業界・分野
   - 地理的な比較可能性

3. **データを収集** (利用可能な場合は MCP ソースを優先します):
   - 営業指標: 収益、成長、売上総利益率、EBITDA、EBITDA利益率
   - 評価: 時価総額、企業価値、EV/収益、EV/EBITDA、PER
   - 業界に基づく追加の指標 (SaaS のルール オブ 40 など)

4. **分析を構築します**:
   - 企業データ + 統計 (最大、75パーセンタイル、中央値、25パーセンタイル、最小) を含む営業統計セクション
   - 同じ統計概要を含む「評価倍率」セクション
   - メモと方法論のドキュメント

<a id="step-3-create-excel-output"></a>
### ステップ 3: Excel 出力を作成する

以下を使用して Excel ファイルを生成します。
- ヘッダーブロック（分析タイトル、企業、日付、単位）
- 営業統計および財務指標セクション
- 「評価倍率」セクション
- 各メトリクスの統計概要
- ソースと方法論を文書化したメモセクション

<a id="step-4-deliver-output"></a>
### ステップ 4: 出力を提供する

以下を提供します:
1. **Excel ファイル** (.xlsx) - 類似企業分析
2. **概要**のハイライト:
   - ピアグループ選択の理論的根拠
   - 重要な洞察 (誰がプレミアム/ディスカウントで取引するか)
   - 参考のための中央値倍数

<a id="industry-specific-metrics"></a>
## 業界固有の指標

| 産業 | 追加の指標 |
|----------|-------------------|
| ソフトウェア/SaaS | ARR、純ドル保持率、ルール オブ 40 |
| 小売 | 既存店売上高、在庫回転数 |
| 金融 | ROE、ROA、効率性比率 |
| 製造業 | 資産回転率、設備投資/収益 |
| ヘルスケア | 研究開発/収益、パイプライン価値 |

<a id="quality-checklist"></a>
## 品質チェックリスト

納品前：
- [ ] 本当に比較可能な企業 4 ～ 6 社
- [ ] 一貫した期間（すべてのLTMまたはすべての会計年度）
- [ ] すべての数式はセルを参照します (ハードコードされた値はありません)
- [ ] ソースを含むすべてのハードコーディングされた入力に対するセルのコメント
- [ ] 統計には最大値、75パーセンタイル、中央値、25パーセンタイル、最小値が含まれます
- [ ] 「メモ」セクションにはソースと方法論が記載されています
- [ ] 青 = 入力、黒 = 式
- [ ] 健全性チェックに合格 (マージンは論理的、倍数は合理的)
