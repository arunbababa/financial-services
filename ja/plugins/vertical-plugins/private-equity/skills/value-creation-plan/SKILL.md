<a id="value-creation-plan"></a>
# 価値創造計画

<a id="workflow"></a>
## ワークフロー

<a id="step-1-baseline-assessment"></a>
### 手順1：現状基準を評価する

出発点を理解する。
- 現在の売上・EBITDA・利益率。
- 組織構造・能力。
- 職能別の主要業務指標。
- 経営陣の強み・不足。
- 調査時に特定済みの短期間で得られる成果。

<a id="step-2-value-creation-levers"></a>
### 手順2：価値創造の手段

全手段を、保有期間のEBITDAブリッジへ対応付ける。

<a id="revenue-growth-levers"></a>
#### 売上成長の手段
- **自力成長：** 値上げ、数量増、市場拡大。
- **クロスセル・アップセル：** 既存顧客へ新製品。
- **新市場：** 地域、新業種、新チャネル。
- **営業の有効性：** 営業採用、転換率改善、期間短縮。
- **M&A・追加買収：** 売上・能力を加える補完買収。

各手段に示す。
- 現状 → 目標。
- 売上影響額（$）。
- 効果発現の時期。
- 必要投資。
- 確信度（高／中／低）。

<a id="margin-expansion-levers"></a>
#### 利益率拡大の手段
- **価格最適化：** 値上げ、構成変化、抱き合わせ。
- **売上原価削減：** 調達節約、供給者集約、自動化。
- **営業費用最適化：** 間接費削減、共通業務、海外移管。
- **技術投資：** 自動化、システム統合、データ分析。
- **規模の効果：** 売上成長による固定費の効率化。

<a id="strategic--multiple-expansion"></a>
#### 戦略・評価倍率上昇
- **プラットフォーム構築：** 追加・小規模補完買収。
- **継続売上への移行：** 単発案件から継続・サブスクリプションへ。
- **市場での位置：** カテゴリー首位、ブランド構築。
- **経営陣強化：** 経営を専門化する重要人材の採用。
- **ESG・統治：** 取締役会の設置、報告改善。

<a id="step-4-100-day-plan"></a>
### 手順4：100日計画

クロージング後100日を優先付けする。

**1〜30日：安定化・評価**
- 経営陣の合意・維持（雇用契約、報酬設定）。
- 短期成果：価格、明白な費用削減、容易な改善。
- 職能別の詳細な業務評価。
- 顧客への伝達計画。
- 報告・KPIダッシュボード整備。

**31〜60日：計画・開始**
- 戦略計画を確定し、組織へ伝える。
- 上位3〜5の価値創造施策を開始する。
- 追加M&Aの候補開拓を始める。
- 重要な不足人材を採用する。
- 週次速報・月次レビュー・四半期取締役会の新しい報告周期を導入する。

**61〜100日：実行・測定**
- 短期施策の最初の成果。
- 業務指標を伴う最初の取締役会。
- 各価値創造手段の進捗報告。
- 初期の学びによる計画調整。

<a id="important-notes"></a>
## 重要事項

- 時間を現実的に考える。PEの価値創造の多くは財務へ表れるまで12〜24か月かかる。
- 短期成果は勢い・信頼に重要だが、成長を犠牲に費用削減へ偏らない。
- 経営陣の賛同が重要。押し付けず共同で作る。
- EBITDA総額だけでなく施策別損益影響を追い、何が効いているかを知る。
- 追加M&Aは最大の手段であることが多い。初日から候補開拓を始める。
- 必ずオペレーティング・パートナーまたは業界専門家と前提を厳しく検証する。
