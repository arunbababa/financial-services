<a id="diligence-meeting-prep"></a>
# デューデリジェンス会議の準備

<a id="workflow"></a>
## ワークフロー

<a id="step-1-meeting-context"></a>
### 手順1：会議の背景

ユーザーへ尋ねる。
- **種類：** 経営陣説明、専門家インタビュー、顧客への評判確認、アドバイザーとの確認、現地視察。
- **出席者：** 対象企業・第三者から誰が出るか。
- **重点：** 事業全般か、財務・事業・業務・技術の特定分野か。
- **既知情報：** 過去の面談、CIM、データルームの発見。
- **主要懸念：** 掘り下げる具体的問題。

<a id="step-2-generate-question-list"></a>
### 手順2：質問一覧

優先度・話題で整理し、会議種別に合わせる。

<a id="management-presentation"></a>
#### 経営陣の説明
**事業概要（導入）**
- 創業経緯と主要な節目を説明してください。
- この業界を知らない人へ、事業をどう説明しますか。
- 最も誇る点と、やり直せるなら変えたい点は何ですか。

**売上・成長**
- 顧客・セグメント・地域別の売上を説明してください。
- 価格、数量、新規顧客のどれが成長を生んでいますか。
- 営業サイクルはどのようなものですか。受注率の推移はどうですか。
- 今後3〜5年の最大の成長機会はどこですか。

**競争上の位置**
- 誰に、なぜ案件を失いますか。
- 競争上の堀は何で、どの程度守れますか。
- 顧客は代替案と比べ、御社をどう評価しますか。

**業務・チーム**
- 組織図と重要人物を説明してください。
- 採用中の役職、最も埋めにくい役職は何ですか。
- 業務面で、夜も気になることは何ですか。

**財務の掘り下げ**
- 利益率の変化を要因分解して説明してください。何がなぜ変わりましたか。
- 理解すべき一時的・非反復項目はありますか。
- 維持投資と成長投資をどう考えますか。
- 運転資本に季節性はありますか。

**今後の見通し**
- 来年の予算・計画を説明してください。
- 最も自信がある・ない前提は何ですか。
- 何がうまくいく・いかないと、大きく計画を超える・下回りますか。

<a id="expert-network-call"></a>
#### 専門家ネットワークへのインタビュー
- [company]の市場での位置をどう見ますか。
- この領域を動かす長期トレンドは何ですか。
- 最も強い競合とその理由は何ですか。
- 投資家が知るべきリスクは何ですか。
- この事業を買うなら、何を最も慎重に調べますか。

<a id="customer-reference-call"></a>
#### 顧客への評判確認
- [company]をどう見つけ、なぜ選びましたか。
- どの代替案を検討しましたか。
- よい点、改善できる点は何ですか。
- 更新・拡大の可能性はどの程度で、何があれば変わりますか。
- 10〜20%値上げされたらどう反応しますか。

<a id="step-3-benchmarks--context"></a>
### 手順3：ベンチマーク・背景

主要テーマごとに関連する比較材料を示す。
- 業界成長率・利益率の水準
- セッションに比較分析があれば類似企業の指標
- CIM・データルームで追加確認すべき数値
- 異なる情報源間で明確にすべき食い違い

<a id="step-4-red-flags-to-probe"></a>
### 手順4：掘り下げる懸念

既知情報から、具体的な調査領域を示す。
- CIM・財務の不整合
- 顧客集中・解約の兆候
- 経営陣の不足・最近の退職
- 通常と異なる会計処理
- データルームの不足項目

<a id="step-5-output"></a>
### 手順5：出力

1ページの準備文書：
1. **開催情報：** 誰・いつ・どこ・長さ。
2. **目的：** 学ぶ必要がある上位3事項。
3. **質問：** 話題別・優先順。必須質問に星印。
4. **ベンチマーク：** 参照する主要数字。
5. **懸念：** 掘り下げる具体事項。
6. **追加確認：** 会議後に求めるもの。

<a id="important-notes"></a>
## 重要事項

- 開かれた質問から始め、経営陣に話してもらってから具体事項を掘る。
- 「……なのは事実ですよね」と誘導せず、中立に問う。
- 回答だけでなく、身振りや確信度も記録する。
- 必ず「まだ尋ねていないが、尋ねるべきことはありますか」で終える。
- 質問は最大15〜20。60〜90分ではそれ以上進められない。
