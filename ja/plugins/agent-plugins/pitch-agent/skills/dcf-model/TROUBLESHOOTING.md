<a id="dcf-model-troubleshooting-guide"></a>
# DCF モデルのトラブルシューティング ガイド

**このファイルを読む場合:** recalc.py でエラーが表示された場合、または評価結果が不合理であると思われる場合、またはケースセレクターが正しく機能していない場合。

<a id="model-returns-error-values"></a>
## モデルがエラー値を返す

<a id="ref-errors"></a>
### #REF!エラー
- 通常、ヘッダーの挿入後に間違った行を参照する数式が原因で発生します。
- 解決策: 正しい行参照を使用して再構築するか、レイアウト計画に従って最初からやり直します。
- 予防策: 式を記述する前にすべての行の位置を定義してください。

<a id="div0-errors"></a>
### #DIV/0!エラー
- ゼロまたは空のセルによる除算
- 解決策: ゼロを処理するための IF ステートメントを追加します: `=IF([Divisor]=0,0,[Numerator]/[Divisor])`

<a id="value-errors"></a>
### #VALUE!エラー
- 計算時のデータ型が間違っています (数値ではなくテキスト)
- 解決策: すべての入力が数値としてフォーマットされていることを確認します。

<a id="valuation-seems-unreasonable"></a>
## 評価が不合理だと思われる

<a id="implied-price-far-too-high"></a>
### モデルが示唆する株価が高すぎる
- 継続価値が EV の 80% を超えていないことを確認してください
- 永久成長率 < WACC を確認する
- 成長の仮定が現実的かどうかを検討する
- マージンが楽観的すぎるかどうかを検討する

<a id="implied-price-far-too-low"></a>
### モデルが示唆する株価が低すぎる
- 純負債と純現金が正しいことを確認する
- WACCが高すぎるかどうかを確認してください
- 予測が保守的すぎるかどうかを確認する
- 永久成長率が低すぎるかどうかを検討する

<a id="case-selector-not-working"></a>
## シナリオ選択セルが機能しない

<a id="consolidation-column-not-updating-when-switching-scenarios"></a>
### シナリオを切り替えるときに統合列が更新されない
- シナリオ選択セルに 1、2、または 3 が含まれていることを確認します
- INDEX/OFFSET 式が正しい行範囲とセレクター セルを参照していることを確認してください。
- セレクターに絶対参照 ($B$6) が使用されていることを確認します。
- セレクター セルを手動で変更し、予測値の更新を確認してテストします。
