<a id="visual-hierarchy-and-layout"></a>
## 視覚的な階層とレイアウト

<a id="box-and-section-layout"></a>
### ボックスとセクションのレイアウト

スライドのレイアウトは、コンテンツの要件とテンプレートのデザインによって異なります。共通の要素には次のようなものがあります。
- タイトルとサブタイトルを含むヘッダー セクション
- ラベルサイドバーのあるコンテンツボックス
- 構造化データのテーブル
- データを視覚的に表現するためのチャート
- スライド下部の脚注バー

特定のレイアウトは、提供されたテンプレートに従う必要があります。一般的なコンテンツ タイプとその典型的な構造:
- **市場定義スライド**: 箇条書きの内容と解説セクションを含むラベルボックス
- **TAM/サイジング スライド**: メトリクスのコールアウト + データ テーブル + 重要なポイント
- **競合分析**: 比較表またはマトリックス
- **財務概要**: サポートデータテーブルを含むグラフ

<a id="alignment-principles"></a>
### 調整の原則

**平行セクションの垂直方向の配置:**

垂直に積み上げられたボックスには、以下の一貫性がある必要があります。
- 左マージン位置
- 箇条書きのインデント
- テキストの開始位置
- ボックスの幅

水平方向に隣接するボックスには、以下の一貫性がある必要があります。
- トップポジション
- 高さ (コンテンツが許可する場合)
- 内部パディング

<a id="text-formatting"></a>
## テキストの書式設定

<a id="bullet-point-structure"></a>
### 箇条書きの構造

非構造化テキストのダンプは避けてください。コンテンツをスキャン可能な箇条書きに分割します。

**正しい構造の例:**
```
✓  Consumer mobile and web language learning apps
   (Duolingo, Babbel, Memrise, Busuu)
✓  B2B enterprise language training platforms
   (goFLUENT, Speexx, Learnship)
✓  Online tutoring marketplaces
   (italki, Preply, Cambly)
```

**間違った構造の例 (テキストダンプ):**
```
Consumer mobile/web apps (Duolingo, Babbel, Memrise, Busuu)
B2B enterprise platforms (Speexx, Rosetta Stone Enterprise)
Online tutoring marketplaces (Preply, italki, Cambly)
```

<a id="bullet-symbol-guidelines"></a>
### 箇条書き記号のガイドライン

| コンテキスト | シンボル | 使用法 |
|---------|--------|-------|
| 含まれる/ポジティブ | ✓ (チェックマーク) | 範囲内の項目、存在する機能 |
| 除外/否定 | ×（十字） | 範囲外の項目、機能がありません |
| 中立リスト | • (箇条書き) | 一般的な列挙、解説 |
| 番号付きシーケンス | 1. 2. 3. | プロセスステップ、ランキング |
| サブ箇条書き | ‣ または – | 主な箇条書きの下の二次的なポイント |

テンプレートの既存の規則に合わせてシンボルの使用を調整します。

<a id="bullet-consistency"></a>
### 箇条書きの一貫性

ボックス/セクション内のすべての箇条書きは同一の書式設定である必要があります。
- ボックス全体で同じ黒丸記号 (意図的に区別しない限り)
- すべての主箇条書きのインデント レベルが同じ
- 同じ箇条書き記号のサイズ
- 箇条書きとテキストの間の間隔が同じである
- 同じレベルのすべての箇条書きテキストで同じフォント サイズ

<a id="font-size-guidelines"></a>
### フォントサイズのガイドライン

これらは一般的な範囲です。テンプレートの仕様に基づいて調整します。

| 要素 | 一般的なサイズ (pt) | スタイル |
|---------|-------------------|-------|
| スライドのタイトル | 40-48 | 太字 |
| サブタイトル/定義 | 18-22 | 太字 |
| セクションヘッダー | 14-16 | レギュラー |
| 本文/箇条書き | 12-14 | レギュラー |
| テーブルヘッダー | 10-12 | 太字 |
| テーブル本体 | 9-11 | レギュラー |
| 脚注 | 8-9 | イタリック体 |

<a id="text-density-guidelines"></a>
### テキスト密度のガイドライン

- **コンテンツ ボックスごとに最大 6 ～ 7 個の箇条書き** (スペースに基づいて調整します)
- **箇条書きあたり最大 2 行**
- **括弧内の例**は同じ行または下にインデントされています
- **孤立した単語を避ける** - 新しい行に単一の単語が含まれないように改行を調整します。

<a id="table-creation"></a>
## テーブルの作成

<a id="critical-use-actual-table-objects"></a>
### 重要: 実際のテーブル オブジェクトを使用する

**表は、タブ間隔のテキストではなく、実際の表オブジェクトである必要があります。**

タブ付きのテキストは適切に配置されず、プロフェッショナルに見えません。常に適切なテーブル オブジェクトを作成してください。

<a id="table-structure-guidelines"></a>
### テーブル構造のガイドライン

1. **列の配置**:
   - テキスト列: 左揃え (ヘッダーとコンテンツの両方)
   - 数値列: 中央揃えまたは右揃え
   - ヘッダーは列の内容と一致する必要があります

2. **ヘッダー行**:
   - 太字のテキスト
   - 影付きの背景 (テンプレートのブランドカラーを使用)
   - 読みやすさを考慮したコントラストのあるテキストカラー
   - 配置は列コンテンツの配置と一致します

3. **交互の行** (オプション):
   - 交互の行に薄い陰影を付けることで可読性が向上します

4. **概要/合計行**:
   - 太字のテキスト
   - 太い上枠（区切り線）
   - 独特の背景の陰影

5. **テーブル幅**:
   - 指定されたセクション幅を埋める
   - テーブルが空白部分に浮いてしまうのを避ける

<a id="chart-and-image-handling"></a>
## チャートと画像の処理

<a id="pasting-charts-from-excel"></a>
### Excel からのグラフの貼り付け

Excel からグラフを貼り付ける場合:

1. **グラフのみを貼り付けます** - ソース データ テーブルは含めないでください
2. **指定された領域を満たすようにサイズを変更します** - グラフは小さなサムネイルとして表示されないようにします
3. **アスペクト比を維持します** - グラフを歪めないでください
4. **可読性を確認** - 軸ラベル、凡例、データ ラベルが判読できる必要があります。

<a id="pasting-tables-from-excel"></a>
### Excel からの表の貼り付け

Excel から表を貼り付ける場合:

1. **書式設定された表のみを貼り付けます** - ソース データや計算は除外します
2. **指定された領域を満たすようにサイズを変更します** - テーブルはセクション全体を占める必要があります
3. **列幅を確認します** - テキストが切り詰められないように調整します
4. **書式設定の保持を確認してください** - 色、境界線、フォントの調整が必要な場合があります

<a id="size-guidelines"></a>
### サイズのガイドライン

**最小サイズ設定の原則:**
- グラフ: 指定された領域のかなりの部分を占める必要があります
- テーブル: 指定されたセクション幅を完全に埋める
- 画像: サムネイルサイズではなく、コンテキストに合わせて適切なサイズに設定されます。

**ビジュアルサイズが小さいことを示すインジケータ (これらは避けてください):**
- グラフが使用可能なスペースのほんの一部を占有している
- テキストラベルが読めない
- ビジュアルを囲む大きな空き領域
- ビジュアルは「サムネイル」として表示されます

<a id="proper-sizing-workflow"></a>
### 適切なサイジングのワークフロー

1. 対象領域の寸法を特定する
2. グラフ/表を貼り付けます
3. ターゲット領域を満たすようにすぐにサイズ変更します
4. すべてのテキストが読み取れる状態であることを確認します
5. 必要に応じて内部要素を調整します (凡例の位置、軸ラベル)

<a id="data-visualization"></a>
## データの視覚化

<a id="key-metrics-display"></a>
### 主要な指標の表示

主要な指標 (TAM、CAGR、予測など) を表示するときは、値を静的にリストするのではなく、値間の関係を示すことを検討してください。

- **ビジュアルフローインジケーター**: 進行状況を示す形状 (矢印、山形、コネクタ)
- **サイズ階層**: プライマリ メトリックのフォントは大きく、ラベルのフォントは小さくなります。
- **空間配置**: 論理的な流れを示すために要素を配置します。

<a id="arrow-and-flow-indicators"></a>
### 矢印とフローインジケーター

矢印またはフローインジケーターを使用する場合:
- テキスト文字ではなく、PowerPoint の図形オブジェクトを使用する
- 最終的なプレゼンテーションではテキストベースの矢印 (→、⟹) を使用しないでください。
- PowerPoint の図形ツールまたは XML 図形要素を使用して矢印を作成する

**XML 実装については、[`xml-reference.md`](../../../../../vertical-plugins/investment-banking/skills/pitch-deck/reference/xml-reference.md#arrow-shapes) を参照してください**

<a id="font-consistency"></a>
## フォントの一貫性

<a id="cross-box-font-consistency"></a>
### クロスボックスフォントの一貫性

同じ階層レベルにあるすべてのテキスト ボックスは、同じフォント サイズを使用する必要があります。

**一致する必要がある同じレベルのボックス:**

| ボックスタイプ | と一致する必要があります |
|----------|-------------------|
| 「セグメントが含まれる」コンテンツ | 「除外されたセグメント」コンテンツ |
| 「定義」の内容 | 「範囲の根拠」の内容 |
| 左列の箇条書き | 右列の箇条書き |
| すべてのラベルボックス | お互いに |
| すべてのセクションのヘッダー | お互いに |

<a id="verification-process"></a>
### 検証プロセス

1. 同じ階層レベルにあるすべてのテキスト ボックスを識別する
2. 各ボックスのフォントサイズを確認する
3. いずれかのボックスが異なる場合は、すべてが一致するように調整します
4. コンテンツが収まる場合は、デフォルトで大きいサイズが設定されます。それ以外の場合は、一貫して小さいサイズを使用してください

**例外**: サブ箇条書きまたは二次テキストでは、主箇条書きよりも小さなフォントを使用できますが、これはすべてのボックスで一貫している必要があります。

<a id="template-adaptation"></a>
## テンプレートの適応

これらの標準は、使用されている特定のテンプレートに一致するように適合させる必要があります。

1. **色**: 特定の色を指定するのではなく、テンプレートのブランドカラーを使用します。
2. **フォント**: テンプレートのフォント ファミリーを使用します。
3. **間隔**: テンプレートの既存の間隔規則と一致します。
4. **レイアウト**: テンプレートのセクション構造に従います。

テンプレートに関係なく変わらない重要な原則は次のとおりです。
- テキストは背景に対して判読できる必要があります
- テーブルは実際のテーブル オブジェクトである必要があります
- コンテンツは利用可能なスペースを適切に埋める必要があります
- 書式設定は並列要素全体で一貫している必要があります
- グラフ/画像は適切なサイズにする必要があります
