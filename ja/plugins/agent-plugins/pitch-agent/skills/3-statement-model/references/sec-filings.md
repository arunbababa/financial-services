# SEC提出書類データ抽出リファレンス

**使用する場合:** このファイルは、モデル テンプレートが SEC提出書類 (10-K、10-Q) からデータを取得する必要がある場合にのみ参照してください。データを直接提供するテンプレート、または他のデータ ソースを使用するテンプレートの場合、この参照は必要ありません。

---

<a id="extracting-data-from-sec-filings-10-k--10-q"></a>
## SEC提出書類からのデータの抽出 (10-K / 10-Q)

公開企業データをモデル テンプレートに入力する場合は、SEC 提出書類から財務情報を直接抽出します。

<a id="step-1-locate-the-filing"></a>
### ステップ 1: ファイリングを見つける

1. SEC EDGAR を使用: `https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK=[TICKER]&type=10-K`
2. 四半期データの場合は、`type=10-Q` を使用します。

<a id="step-2-identify-filing-currency"></a>
### ステップ 2: 提出書類の報告通貨を特定する

データを抽出する前に、レポート通貨を特定します。
- 報告通貨については表紙またはヘッダーを確認してください
- 明細書のヘッダーを確認します (例: 「数千米ドル」)
- レビュー注記 1 (重要な会計方針の概要)

**一般的な通貨インジケーター**

| インジケーター | 通貨 |
|-----------|----------|
| $、USD | 米ドル |
| €、EUR | ユーロ |
| £、GBP | 英国ポンド |
| ¥、JPY | 日本円 |
| ¥、CNY、RMB | 中国人民元 |
| CHF | スイスフラン |
| CAD、C$ | カナダドル |

モデル通貨を申告に合わせて設定します。 「前提条件」タブのドキュメント。

<a id="step-3-navigate-to-financial-statements"></a>
### ステップ 3: 財務諸表に移動する

10-K または 10-Q 内で、次の場所を見つけます。
- **項目 8** (10-K) または **項目 1** (10-Q): 財務諸表
- 抽出する重要なセクション:
  - 連結経営計算書（損益計算書）
  - 連結貸借対照表
  - 連結キャッシュ・フロー計算書
  - 財務諸表注記（スケジュール詳細用）

<a id="step-4-data-extraction-mapping"></a>
### ステップ 4: データ抽出マッピング

**損益計算書（連結損益計算書より）**

| 提出書類の項目 | モデルの項目 |
|------------------|-----------------|
| 純収益・純売上高 | 収益 |
| 売上原価 | COGS（売上原価） |
| 販売・一般管理 | 販管費 |
| 減価償却費と償却費 | D&A |
| 支払利息、純額 | 支払利息 |
| 所得税費用 | 税金 |
| 当期純利益 | 当期純利益 |

**貸借対照表（連結貸借対照表より）**

| 提出書類の項目 | モデルの項目 |
|------------------|-----------------|
| 現金および現金同等物 | 現金 |
| 売掛金、純額 | AR |
| 在庫 | 在庫 |
| 有形固定資産純額 | PP&E (ネット) |
| 総資産 | 総資産 |
| 買掛金 | AP |
| 短期借入金 / 1年以内に返済予定のLT債務 | 流動負債に分類される有利子負債 |
| 長期債務 | 長期有利子負債 |
| 利益剰余金 | 利益剰余金 |
| 株主資本合計 | 総資本 |

**キャッシュ・フロー計算書（連結キャッシュ・フロー計算書より）**

| 提出書類の項目 | モデルの項目 |
|------------------|-----------------|
| 当期純利益 | 当期純利益 |
| 減価償却費と償却費 | D&A |
| 売掛金の変動 | ΔAR |
| 在庫の推移 | Δ在庫 |
| 買掛金の変動 | ΔAP |
| 設備投資 | 設備投資 |
| 普通株式の発行による収入 | 株式の発行 |
| 借入金による収入・返済 | 債務の増減 |
| 配当金支払額 | 配当金 |

<a id="step-5-extract-supporting-detail-from-notes"></a>
### ステップ 5: 注記から裏付けとなる詳細を抽出する

補助明細には、財務諸表の注記からデータを取得します。
- **注: 負債** → 満期スケジュール、金利、制限事項
- **注: 有形固定資産** → 総PP&E、減価償却累計額、耐用年数
- **注: 収益** → セグメントの内訳、地理的分割
- **注: リース** → オペレーティング リース債務とファイナンスリース債務

<a id="step-6-historical-data-requirements"></a>
### ステップ 6: 履歴データの要件

少なくとも 3 年間の履歴データを抽出します。
- 10-K は 3 年間の IS/CF、2 年間の BS を提供します
- 3 年目の BS の場合は、前年度の 10-K から引き出します
- 必要に応じて、10-Q を使用して四半期ごとの粒度を入力します

<a id="data-extraction-checklist"></a>
### データ抽出チェックリスト

- 報告通貨と規模（数千、数百万）を特定する
- 過去 3 年間の損益計算書
- 過去 3 年間のキャッシュ フロー計算書
- 過去 3 年間の貸借対照表
- IS 純利益 = CF 開始純利益 (各年) を確認します。
- BS キャッシュ = CF 期末キャッシュ (各年) を検証します。
- 注記から債務満期スケジュールを抽出する
- D&A の詳細または耐用年数の仮定を抽出する
- 正規化する非定期的または 1 回限りの項目に注意してください

<a id="handling-common-filing-variations"></a>
### 一般的なファイリングのバリエーションの処理

| バリエーション | 取り扱い方法 |
|-----------|---------------|
| COGS/SG&Aに組み込まれたD&A | キャッシュ フロー計算書から D&A を取得する |
| 「その他」の項目に重要性がある | 内訳を注記で確認する |
| 過年度の修正再表示 | 修正再表示後の数値を使い、Assumptionsに注記します |
| 会計年度≠暦年 | 会計年度のラベル (例: 2025 年 1 月期) |
| USD 以外の報告通貨 | 申告に合わせてモデル通貨を調整する |
