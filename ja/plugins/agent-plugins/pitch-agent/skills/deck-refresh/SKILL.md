<a id="deck-refresh"></a>
# デッキリフレッシュ

デック全体の数値を更新します。デッキはフォーマットに関する信頼できる情報源です。値を変えているだけです。

<a id="environment-check"></a>
## 環境チェック

このスキルは、PowerPoint アドインとチャットの両方で機能します。開始する前に、自分がどちらにいるのかを確認してください。編集方法は異なりますが、意図は同じです。

- **アドイン** — 資料はアプリ内で開かれています。テキストラン、表のセル、グラフデータを直接編集します。
- **チャット** — デッキはアップロードされたファイルです。影響を受けるスライドを新しい値で再生成し、結果を書き戻すことで編集します。

いずれの方法でも、変更は最小限に抑えられ、既存の書式設定はそのまま残ります。

これは 4 段階のプロセスであり、3 番目の段階は承認ゲートです。ユーザーがプランを確認するまでは編集しないでください。

<a id="phase-1--get-the-data"></a>
## フェーズ 1 — データを取得する

`ask_user_question` を使用して、新しい数値がどのように到着するかを確認します。

- **貼り付けられたマッピング** - ユーザーは「収益 $485M → $512M、EBITDA $120M → $135M」を入力または貼り付けます。最も明確なケース。
- **アップロードされた Excel** — 古い/新しい列、またはユーザーが取得したい新しい出力シート。信頼する前に、読んで、どの列がどの列であるかを確認してください。
- **新しい値のみ** — 「第 4 四半期の収益は 5 億 1,200 万ドル、利益率は 22% でした。」それぞれが何を置き換えるかを理解します。実行可能ですが、何かに触れる前にマッピングを確認してください。「5 億 1,200 万ドル」を収益にマッピングしても、ユーザーにとっては売上総利益を意味していた場合、静かな災害となります。

**導出された数値**についても質問します。収益が変動した場合、ユーザーは成長率とシェアのパーセンテージを再計算することを望んでいますか、それともそのままにしておきますか?ほとんどのデッキには「+15% YoY」が組み込まれていますが、それは今では陳腐化しています。これらに触れるかどうかは、ユーザーが判断すべきものであり、あなたではありません。

<a id="phase-2--read-everything-find-everything"></a>
## フェーズ 2 — すべてを読み、すべてを見つける

すべてのスライドを読みます。古い値ごとに、同じに見えないものも含めて、すべてのインスタンスを検索します。

| バリアント | 例 |
|---|---|
| スケール | `$485M`, `$0.485B`, `$485,000,000` |
| 精度 | `$485M`, `$485.0M`, `~$485M` |
| ユニットスタイル | `$485M`, `$485MM`, `$485 million`, `485M` |
| 埋め込み型 | 「収益は 4 億 8,500 万ドルに成長」、「4 億 8,500 万ドルのビジネス」、axis ラベル |

スライド 3 に `$485M`、スライド 8 のグラフ軸に `485`、スライド 15 の脚注に `$485.0 million` と記載されているデッキには、同じ数値のインスタンスが 3 つあります。検索置換ではそのうち 2 つが欠落します。そうすべきではありません。

**数字が隠れている場所:**
- テキストボックス (当然のこと)
- 表のセル
- グラフのデータラベルと軸ラベル
- グラフのソース データ — バー上のラベルだけでなく、バーを駆動する数値
- 脚注、ソース行、小さな文字
- スピーカーノート (ユーザーがそれを気にする場合)

リストを作成します。古い値ごとに、それが表示されるすべての場所、表示される正確なテキスト、およびそれがどのようになるかについて説明します。このリストは計画です。

<a id="phase-3--present-the-plan-get-approval"></a>
## フェーズ 3 — 計画を提示し、承認を得る

**これは、誰かが時間を費やしたデッキに対する破壊的な操作です。** 1 つのものを編集する前に、完全な変更リストを表示してください。スキャンできるようにフォーマットします。

```
$485M → $512M (Revenue)
  Slide 3  — Title box: "Revenue grew to $485M"
  Slide 8  — Chart axis label: "485"
  Slide 15 — Footnote: "$485.0 million in FY24 revenue"

$120M → $135M (Adj. EBITDA)
  Slide 3  — Table cell
  Slide 11 — Body text: "$120M of Adj. EBITDA"

FLAGGED — possibly derived, not in your mapping:
  Slide 3  — "+15% YoY" (growth rate — stale if base year didn't change?)
  Slide 7  — "12% market share" (was this computed from $485M / market size?)
```

フラグが立てられたセクションが重要です。単に検索と置換を実行しているだけではなく、ユーザーが午後 11 時に見逃していたであろう二次効果を捉えることになります。マッピングに `$485M → $512M` と表示され、スライド 3 のすぐ隣にも `+15% YoY` がある場合、その成長率はおそらく間違っています。フラグを立ててください。黙って修正したり、黙って放置したりしないでください。

承認には `ask_user_question` を使用します。示されているとおりに続行するか、続行してフラグの付いた項目をスキップするか、最初にマッピングを修正させます。

<a id="phase-4--execute-preserve-report"></a>
## フェーズ 4 — 実行、保存、レポート

変更ごとに、それを達成するための最小限の編集を行います。それがどのように起こるかは環境によって異なります。

- **アドイン** — 特定のテキストラン、セル、またはチャート シリーズをライブデッキで直接編集します。
- **チャット** — 他のすべての要素をそのまま保持して、影響を受けたスライドを新しい値で再生成し、ファイルに書き戻します。

どちらの場合でも、標準は同じです。

- **図形内のテキスト** — 値を変更し、フォント/サイズ/色/太字の状態をそのままにします。 `$485M` が文内で 14 ポイントの紺色の太字である場合、同じ文内で `$512M` は 14 ポイントの紺色の太字になります。
- **表のセル** — 表はそのままにして、セルを変更します。
- **グラフ データ** — 棒/線が実際に移動するように、基になる系列の値を更新します。データを使用せずにラベルだけを編集すると、グラフが嘘のまま残ります。

触れる必要のないものは再フォーマットしないでください。デッキの既存のスタイルは定義上正しいです。あなたは外科医であり、リノベーターではありません。

最後の編集後に、実際に何が起こったかを報告します。

```
Updated 11 values across 8 slides.

Changed:
  [the list from Phase 3, now past-tense]

Still flagged — did NOT change:
  Slide 3 — "+15% YoY" (derived; confirm separately)
  Slide 7 — "12% market share"
```

編集されたすべてのスライドで標準の視覚的検証チェックを実行します。長くなった数値 (`$485M` → `$1,205M`) は、テキスト ボックスをオーバーフローしたり、テーブルの列幅を押し広げたりする可能性があります。ユーザーが気づく前にそれをキャッチします。

<a id="what-youre-not-doing"></a>
## あなたがしていないこと

- **スライドを再構築しない** — スライドの説明が新しい数値で意味をなさなくなった場合 (「利益率が低下した」が利益率が上がった場合)、フラグを立てて書き直さないでください。
- **要求されない限り再計算しません** — 導出された数値はユーザーの判断によるものです。フェーズ 1 の質問ではこれについて説明します。
- **書式設定には触れない** — デッキが `$MM` を使用し、ユーザーのマッピングが `$M` となっている場合は、マッピングではなく資料内の既存の表記に合わせます。値は変わります。スタイルは残ります。
