<a id="language-patterns-to-avoid"></a>
## 避けるべき言語パターン

- **英語の短縮形**：Don't → Do not、won't → will not
- **感嘆符**: 通常、IB マテリアルには不適切です。
- **一人称**: 「私たちは... と考えます」 → 「経営陣は... と信じています」または受動態
- **証拠のない最上級**: 「クラス最高」には裏付けとなるデータが必要です
- **曖昧な数量詞**: 「いくつかの」、「多くの」、「いくつかの」 → 特定の数字

<a id="preferred-phrasing-patterns"></a>
## 好ましいフレージングパターン

**成長物語**:
- 「X% の収益 CAGR という実証済みの実績」
- 「[期間]にわたって一貫した利益率の拡大」
- 「有機的な成長を生み出す実証済みの能力」

**市場での地位**:
- 「[特定のセグメント] の #X プレーヤー」
- 「[特定のサービス] の大手プロバイダー」
- 「[特定の属性] による差別化されたポジショニング」

**戦略的根拠**:
- 「魅力的な戦略的適合性を推進する...」
- 「...を通じた魅力的な価値創造の機会」
- 「[特定のソース] からの X 百万ドルの相乗効果の可能性」
