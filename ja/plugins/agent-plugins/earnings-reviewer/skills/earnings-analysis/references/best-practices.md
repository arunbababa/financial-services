# ベストプラクティス、例、品質ガイドライン

この文書では、例、作成のヒント、避けるべき一般的な誤り、包括的な品質チェックリストを示す。

<a id="example-headlines"></a>
## 見出しの例

<a id="good-earnings-update-headlines"></a>
### 良い決算更新レポートの見出し:
- 「Nike 2024年度第2四半期：DTCの好調が卸売の不振を相殺 — オーバーウェイト（OW）維持、目標株価（PT）95ドル」
- 「Tesla 2024年第3四半期：Cybertruckの生産拡大が計画を先行 — 業績予想を引き上げ、目標株価を285ドルへ」
- 「LVMH 2024年第4四半期：ファッション・レザーは底堅く、ワインは低調 — 予想並み、買い推奨を継続」
- 「Apple 2024年度第1四半期：サービスは予想を上回り、iPhoneは下回る — 強弱入り交じる四半期、目標株価を185ドルへ引き下げ」

<a id="bad-headlines-avoid"></a>
### 悪い見出し（避けること）:
- 「Nikeの四半期更新」（一般的すぎて、重要な結論がない）
- 「企業が決算を発表」（自明な事実を述べるだけで、分析がない）
- 「第3四半期決算分析」（企業名も見解もない）

<a id="tips-for-success"></a>
## 作成のヒント

1. **スピードが重要**: 何日も後にせず、決算発表後24～48時間以内に公表する。

2. **結論から書く**: 予想を上回ったか、下回ったか。業績予想を引き上げるか、引き下げるか。

3. **すべてを数値で示す**: 「好調」だけでは伝わらない。「売上高12億ドル、予想を1億5,000万ドル上回る」なら明確。

4. **変動要因に焦点を当てる**: 「売上高が予想を上回った」と述べるだけでなく、その理由を説明する。

5. **計算・判断の過程を示す**: 従来予想 → 新予想を、その理由とともに示す。

6. **重要な変化があれば目標株価を更新する**: 業績予想が5%超変わる場合、通常は目標株価も変わる。

7. **決算説明会の内容を反映する**: プレスリリースだけを分析せず、経営陣の発言を参照する。

8. **同業他社と比較する**: 類似企業がすでに決算を発表していれば、相対的な業績を記載する。

9. **簡潔に書く**: 包括的なレポートではないため、四半期決算に焦点を絞る。

10. **トレンドをグラフにする**: 四半期推移のグラフが最も有用。

<a id="common-mistakes-to-avoid"></a>
## 避けるべき一般的な誤り

❌ **網羅しすぎる**: 四半期決算について、カバレッジ開始レポート並みの長さで書かない。

❌ **予想の上振れ・下振れがない**: 実績が予想を上回ったか下回ったかを冒頭に示す。

❌ **業績予想を更新しない**: 更新した将来の業績予想を必ず示す。

❌ **曖昧な表現**: 数値を伴わない「好調な業績」。

❌ **会社業績見通しを無視する**: 企業がガイダンスを示していれば、十分に分析する。

❌ **遅すぎる**: 決算発表から5日以上経って公表すると、時宜を失う。

❌ **基本情報の繰り返し**: 企業の事業内容の説明に3ページを費やさない。

❌ **目標株価の更新漏れ**: 業績予想が大きく変わった場合は、目標株価も変更すべき。

❌ **投資判断への影響がない**: 実績を投資判断の根拠と投資評価に結び付ける。

❌ **出典の欠落**: すべての数値に、クリック可能なハイパーリンク付きの出典が必要。

❌ **プレーンテキストのURL**: すべてのURLを、クリック可能なハイパーリンクとして設定する。

<a id="comprehensive-quality-control-checklist"></a>
## 包括的な品質管理チェックリスト

決算更新レポートの納品前に、以下の全項目を確認する。

<a id="content--analysis-checklist"></a>
### 内容・分析のチェックリスト

**予想の上振れ・下振れ分析:**
- [ ] レポート冒頭に予想の上振れ・下振れ分析がある
- [ ] 差異を具体的に数値化している（例：「予想を1億2,000万ドル、率にして3%上回る」）
- [ ] 実績が予想と異なった理由を説明している
- [ ] 各主要指標（売上高、EPS、利益率など）を分析している

**指標と業績:**
- [ ] すべての主要指標を前年同期比（YoY）とともに説明している
- [ ] 必要に応じて前四半期比（QoQ）を含めている
- [ ] セグメント別・地域別・製品別の内訳を示している
- [ ] 事業指標（顧客数、ARPU、販売数量など）を分析している

**会社業績見通しとアナリスト予想:**
- [ ] 会社業績見通しが示されている場合、その変更を分析し、数値化している
- [ ] 会社業績見通しがない場合は、その旨を明記している
- [ ] 当期の業績予想を更新している
- [ ] 翌期の業績予想を更新している
- [ ] 従来予想と新予想を明確に比較している
- [ ] 変更内容とその理由を説明している

**バリュエーションと投資評価:**
- [ ] 決算内容が変更を正当化する場合、目標株価を更新している
- [ ] 目標株価が変わらない場合、維持することを明記している
- [ ] バリュエーションの手法を説明している
- [ ] 明確な根拠とともに投資評価を維持または変更している
- [ ] 投資判断の根拠を評価し、必要に応じて更新している

<a id="format--length-checklist"></a>
### 書式と分量のチェックリスト

**全体構成:**
- [ ] レポートが8～12ページである（これより短くも長くもしない）
- [ ] 1ページ目が決算概要の形式になっている
- [ ] 1ページ目のタイトルに「EARNINGS UPDATE」がある（「Initiating Coverage」ではない）
- [ ] 決算などのイベントに即したタイトルである（例：「好調な第3四半期決算…」）

**表:**
- [ ] 概要表が1～3点ある（詳細を網羅した表ではない）
- [ ] すべての表に明確な列見出しがある
- [ ] すべての表の見出し行に網掛けがある
- [ ] すべての表の下部に出典行がある
- [ ] 業績予想表に従来予想・新予想・増減の列がある

**グラフ:**
- [ ] 文書全体にグラフを8～12点埋め込んでいる
- [ ] すべてのグラフの上に「Figure X - [Title]」のキャプションがある
- [ ] すべてのグラフの下に「Source: [Source]」の行がある
- [ ] グラフが四半期推移に焦点を当てている
- [ ] グラフで変化（予想の上振れ・下振れ、予想修正）を強調している
- [ ] グラフがプロフェッショナルな体裁である

<a id="citations--sources-checklist--mandatory"></a>
### 引用・出典のチェックリスト ⭐⭐⭐ 必須

**図表の出典:**
- [ ] すべての図に、文書名と日付を伴う具体的な出典がある
- [ ] すべての表に、参照文書を示す具体的な出典がある
- [ ] 該当する場合、出典にページ番号またはスライド番号がある

**予想の上振れ・下振れの出典:**
- [ ] 予想の上振れ・下振れ分析で、コンセンサス予想の出典（Bloomberg、FactSetなど）を引用している
- [ ] コンセンサス予想の出典に、いつの時点の予想かを示している（決算発表前の市場引け時点）
- [ ] 企業の公表実績について、決算発表資料またはForm 10-Qを出典としている

**会社業績見通しの出典:**
- [ ] 現行の会社業績見通しについて、決算説明会の書き起こしまたは決算発表資料を出典としている
- [ ] 従来の会社業績見通しについて、前四半期の資料を出典としている
- [ ] 現行と従来の両方の会社業績見通しの出典にハイパーリンクがある

**統計・指標:**
- [ ] 主要な統計に出典付きの脚注がある
- [ ] 脚注が具体的な文書とページ番号・スライド番号を参照している
- [ ] 経営陣の発言の引用に、発言者名と出典文書を記載している

**ハイパーリンク:** ⭐⭐⭐ 重要
- [ ] すべてのURLがクリック可能なハイパーリンクである（プレーンテキストではない）
- [ ] ハイパーリンクに意味の分かる表示テキストを設定している
- [ ] Word文書では青色・下線付きのハイパーリンク書式にしている
- [ ] ハイパーリンクをテストし、動作を確認している（Ctrl+クリックで正しいページが開く）
- [ ] すべてのSEC提出書類がEDGARビューアにリンクしている
- [ ] すべての決算関連資料（発表資料、書き起こし、プレゼンテーション）にハイパーリンクがある
- [ ] 比較用の前四半期資料にハイパーリンクがある
- [ ] 文書内のどこにもURLをそのまま表示していない

**出典セクション:**
- [ ] レポート末尾に「Sources & References」セクションがある
- [ ] すべての決算関連資料を日付とともに列挙している
- [ ] すべての資料にクリック可能なハイパーリンクがある
- [ ] コンセンサスデータの出典を列挙している（有料データへのリンクがない場合も含む）
- [ ] 過去期間の参照資料を含めている

<a id="accuracy-checklist"></a>
### 正確性のチェックリスト

**数値の正確性:**
- [ ] 数値が企業の公表実績と完全に一致している
- [ ] すべての計算が整合している
- [ ] 業績予想の変更率を正しく計算している
- [ ] バリュエーションの計算が正確である
- [ ] グラフと本文の説明が一致している

**事実の正確性:**
- [ ] ティッカーシンボルに誤記がない
- [ ] 企業名に誤記がない
- [ ] 日付が最新かつ正確である
- [ ] 四半期・年度の記載が正しい
- [ ] 年度の表記が正しい（Aは実績、Eは予想）

<a id="timeliness-checklist"></a>
### 適時性のチェックリスト

**公表のタイミング:**
- [ ] 決算発表後24～48時間以内にレポートを公表している
- [ ] 48時間を超える場合、遅れての反応である旨（「delayed reaction」）を明記している
- [ ] ✅ **直近の決算を検索し、すべてのデータが最新四半期のものであることを確認した**
- [ ] ✅ **知識のカットオフに依存せず、現時点のデータを実際に検索した**
- [ ] コンセンサス予想が決算発表前時点のものである（発表後ではない）
- [ ] 古い情報を含めていない
- [ ] 決算発表日が直近1～3か月以内である（6か月以上前ではない）

<a id="writing-style-checklist"></a>
### 文体のチェックリスト

**明確さと直接性:**
- [ ] 数値から書いている（「売上高が好調」ではなく「売上高は15%増の12億ドル」）
- [ ] 英語では「versus」ではなく「vs.」を使っている
- [ ] 全体を通して直接的かつ簡潔に書いている
- [ ] 新しい情報に焦点を当てている（企業の基本情報を繰り返さない）
- [ ] 曖昧な表現を避けている（数値を伴わない「好調な業績」など）

**専門的な基準:**
- [ ] 機関投資家向けの文体を保っている
- [ ] 全体で用語が統一されている
- [ ] くだけた表現がない
- [ ] 適切な財務表記を使っている

<a id="pre-delivery-final-check"></a>
## 納品前の最終確認

レポートをユーザーへ送る前に、次の簡単な最終確認を行う。

<a id="5-minute-final-review"></a>
### 5分間の最終レビュー:
1. **1ページ目**: 投資評価は明確か。目標株価は更新したか。主要なポイントに説得力があるか。
2. **数値**: 実績値は企業のプレスリリースと完全に一致しているか。
3. **出典**: 図表を3～4点抜き取り、すべてにクリック可能なハイパーリンク付きの出典があるか確認する。
4. **業績予想**: 従来予想と新予想を明確に示したか。変更理由を説明したか。
5. **グラフ**: 8～12点をすべて埋め込んだか。すべてに番号とキャプションがあるか。
6. **分量**: 8～12ページか（6ページや15ページではないか）。
7. **ハイパーリンク**: 3～4点をテストし、Ctrl+クリックで動作するか確認する。
8. **適時性**: 決算発表から48時間以内に公表できるか。

すべての項目を満たせば、レポートを納品できる。

<a id="summary-delivery-format"></a>
## 納品時の概要形式

完成したレポートをユーザーに渡す際は、以下の概要を添える。

日本語補訳：[企業]の第[X]四半期[年度]の決算更新が完了した旨を示す。実績（Results）は「予想超過／予想並み／予想未達」、売上高（Revenue）は金額と予想に対する上振れ・下振れの金額・率、EPS（1株当たり利益）は金額と予想との差額を記載する。主要ポイント3点の後に、当年度の売上高・EPSの新予想、従来予想（prior）、増減率を示す。投資評価（Rating）は維持／引き上げ／引き下げと評価区分を、目標株価は新旧の値と現在株価に対する上昇余地（upside）を記す。成果物は8～12ページのDOCX決算更新レポート、埋め込みグラフ8～12点、従来・新予想の比較、クリック可能なハイパーリンク付きの完全な出典セクション、任意の更新済みXLS財務モデル。最後にファイル名を示す。Bは十億ドル、Mは百万ドル、FYは会計年度、Eは予想を意味する。

```
[Company] Q[X] [Year] Earnings Update Complete

Results: [BEAT / INLINE / MISS]
- Revenue: $X.XB ([beat/missed] by $XXM or X%)
- EPS: $X.XX ([beat/missed] by $X.XX)

Key Takeaways:
■ [Takeaway 1]
■ [Takeaway 2]
■ [Takeaway 3]

Updated Estimates:
- FY[Year]E Revenue: $XX.XB (prior: $XX.XB, [+/-]X%)
- FY[Year]E EPS: $X.XX (prior: $X.XX, [+/-]X%)

Rating: [MAINTAINED / RAISED / LOWERED] [RATING]
Price Target: $XXX (prior: $XXX) - [+/-]XX% upside

Deliverables:
✓ 8-12 page earnings update report (DOCX)
✓ 8-12 embedded charts
✓ Updated estimates with old/new comparison
✓ Complete sources section with clickable hyperlinks
✓ [Optional: Updated XLS financial model]

File: [Company]_Q[X]_[Year]_Earnings_Update.docx
```
