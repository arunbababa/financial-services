<a id="competitive-landscape-mapping"></a>
# 競争環境のマッピング

完全な競合分析デッキを構築します。これは 2 段階のプロセスです。最初に要件を収集し、概要の承認を得てから構築します。

<a id="environment-check"></a>
## 環境チェック

このスキルは、PowerPoint アドインとチャットの両方で機能します。開始する前に、自分がどちらにいるのかを確認してください。操作方法は異なりますが、作業手順は同じです。

- **アドイン** — 資料はアプリ内で開かれています。そこにスライドを直接構築します。
- **チャット** — `.pptx` ファイルを生成します (またはユーザーがアップロードしたファイルに組み込みます)。

以下のすべては両方に当てはまります。

<a id="phase-1--scope-the-analysis"></a>
## フェーズ 1 — 分析の範囲を設定する

競合分析は人によって意味が異なります。リサーチやスライド作成の前に、`ask_user_question` を使用して、ユーザーが実際に望んでいることを特定します。推測しないでください。20 枚のスライドからなるピア ベンチマーク資料と 5 枚のスライドからなる市場マップはどちらも「競合分析」であり、まったく異なる形になります。

可能なら一度に確認します（ツールは最大4問を受け付けます）。

- **範囲** — 周囲に競合他社がいる単一のターゲット企業ですか?それとも主役のいない複数の企業が並列するのでしょうか?
- **競合他社のセット** — どの企業が対象ですか?ユーザーが名前を付ける場合は、そのとおりに使用してください。 「通常の主要企業」と言われたら、セットを提案して確認します。
- **対象読者と深さ** — すでにその分野に携わっている人向けの簡単な読み物ですか、それとも完全な入門書ですか?これにより、市場規模、業界の経済学、歴史が必要かどうかが決まります。あるいは、比較までスキップすることもできます。
- **投資の背景** — 強気/ベース/弱気のシナリオと道しるべは必要ですか?それが以下のステップ 9 です。これが投資仮説ではなく戦略的なレビューの場合は飛ばしてください。

競合他社のデータを含む Excel/CSV をアップロードしている場合は、数値の取得を開始する前に、どの列がどの指標にマップされているかを確認してください。ソース ファイルの忠実度は重要です。値は指定されたとおりに使用し、再計算や再四捨五入は行わないでください。

<a id="phase-2--outline-approve-then-build"></a>
## フェーズ 2 — 概要を示し、承認し、構築する

**概要が承認されるまではスライドを作成しないでください。** スライドのタイトルと 1 行の内容メモを提案し、ユーザーに提示し、「はい」をもらいます。競合分析資料は、連動するコンテンツの 10 ～ 20 枚のスライドで構成されます。スライド 4 が間違っていたために再構築するにはコストがかかります。アウトラインは安価な反復ポイントです。

アウトラインを提案する際、`ask_user_question` は、どのようなポジショニングを視覚化するか (2×2 マトリックス / レーダー / 階層図 — 以下のステップ 5)、競合他社をどのようにグループ化するか (ビジネス モデル / セグメント / 姿勢別 — ステップ 4) といった構造的な決定にうまく機能します。これらはユーザーが意見を持っている可能性が高い好みの判断です。

<a id="standards--apply-throughout"></a>
## 標準 — 全体に適用

<a id="prompt-fidelity"></a>
### 依頼内容への忠実さ

ユーザーが何かを指定する場合、それは提案ではなく要件です。
- **スライドのタイトルとセクション名** — 正確な表現。 「概要と競争範囲」と書かれている場合は、「2024 年度の競争状況」を入れ替えないでください。
- **グラフと表** — 互換性はありません。 「埋め込みグラフ」とは、書式設定された表ではなく、棒/スライスにデータ ラベルが付いた実際のグラフ オブジェクトを意味します。
- **完全なデータ シリーズ** — 7 社の競合他社がリストされている場合は、7 社すべてを含めます。2015 年から 2025 年までを示している場合は、すべての年を含めます。
- **正確な値と比率** — 「DoorDash 4:1、Lyft 8:1 を超える」とはそれらの比率を意味し、「7.6x Lyft」ではありません。

<a id="source-quality-when-sources-conflict"></a>
### ソースの品質、ソースが競合する場合

1. 10-K / 年次報告書 (監査済み)
2. 決算説明会・投資家説明会（経営陣の解説）
3. セルサイド調査（アナリストの推定値、非公開企業の規模決定に役立ちます）
4. 業界レポート (マッキンゼー、ガートナー – 市場規模、トレンド)
5. ニュース (最近の動向のみ。一次情報源と照合して確認してください)

<a id="data-comparability"></a>
### データの比較可能性

- 同じ会計年度のすべての競合他社の指標。例外に明示的にフラグを付ける (「2024 年度」と「2024 年上半期」)
- 競合他社間で同じ指標定義
- 海外の場合は米ドルに変換します。為替レートと日付に注意してください
- 欠損データは「-」または「N/A」として表示され、推定値として「[E]」フラグが付けられます。空白になることはありません
- すべての数値に出典を付けます: 「[会社] [文書] ([日付])」

<a id="design"></a>
### デザイン

- **スライドのタイトルはラベルではなく洞察です。** 「大手企業がニッチ プレーヤーから引き離す」 - 「競合分析」ではありません。
- **判断の兆候・基準は数値化します。** 「利益率が 40% 未満」 — 「利益率の低下」ではありません。
- **格付けは実際の値を示しています。** 「●●● $160B」 — 単なる「●●●」ではありません。
- **グラフは実際のグラフ オブジェクトです**。グラフのように見せかけたテキスト テーブルではありません。

**タイポグラフィ** — 明示的に設定します。デフォルトに依存しません。
- スライドのタイトル: 28 ～ 32 ポイントの太字
- セクションヘッダー: 18 ～ 20 ポイントの太字
- 本文: 14～16pt (14pt を下回らない)
- 表のテキスト: 14pt
- 出典/脚注: 14pt、グレー
- 同じ要素タイプ = デッキ全体で同じサイズ

**チャート:**
- 凡例はグラフの境界内にあり、プロット領域に重ねて浮かせない
- 円グラフの右側の凡例 (スライス 6 個以下)、折れ線/棒の下部の凡例 (シリーズ 4 個以下)
- 6 シリーズを超える → 複数のグラフに分割するか、表を使用します
- 円グラフには、凡例だけでなくスライスのパーセンテージも表示されます

**テーブル:**
- ライトグレーのヘッダー行、太字
- 数字は右揃え、テキストは左揃え
- テキストが境界線に触れないように十分なセルのパディング

**色:** 最大 2 ～ 3 色。落ち着いた色 - ネイビー、グレー、アクセントが 1 つあります。全体を通して同じ色の意味。

<a id="whats-strict-vs-flexible"></a>
### 厳格か柔軟か

| いつも | ケースバイケース |
|---|---|
| ユーザーが指定した場合の正確なタイトル/セクション | そうでない場合のクリエイティブなタイトル |
| ユーザーがチャートと言うとチャート;彼らがテーブルと言うときはテーブル | 未指定の場合の視覚化タイプ |
| リストされているすべての競合他社/データポイント | 競合企業の数が指定されていない場合 |
| 指定された場合の正確な値 | 精度が指定されていない場合の丸め |
| タイトルがオーバーフローせずに収まる | 競合カテゴリーの数 |
| 重複する要素はありません | どのディメンションを比較するか |

<a id="analysis-workflow"></a>
## 分析ワークフロー

<a id="step-0--industry-defining-metrics"></a>
### ステップ 0 — 業界を定義する指標

何よりもまず、この業界は実際に 3 ～ 5 つのどのような指標に基づいて運営されているのでしょうか?これらをすべての競合他社で一貫して使用してください。

| 産業 | 主要な指標 |
|---|---|
| SaaS | ARR、NRR、CACペイバック、LTV/CAC、ルール・オブ・40 |
| 支払い | GPV、テイクレート、アタッチレート、トランザクションマージン |
| マーケットプレイス | GMV、テイクレート、買い手/売り手の比率、リピート率 |
| 小売 | 既存店売上高、在庫回転率、平方フィートあたりの売上高 |
| 物流 | 量、ユニットあたりのコスト、納期厳守率、稼働率 |

リストされていない業界 — 投資家と事業者のベンチマークとなる指標を選択してください。

<a id="step-1--market-context"></a>
### ステップ 1 — 市場の状況

規模、成長、要因、逆風。ソース付き。

正解: 「エンベデッド ペイメントは 2024 年に 800 ～ 1000 億ドルとなり、CAGR は 20 ～ 25% 成長します (McKinsey 2024)」
間違い: 「市場は大きく、急速に成長している」

<a id="step-2--industry-economics"></a>
### ステップ 2 — 業界の経済性

価値がどのように流れるかをマップします。アプローチは業界構造によって異なります。
- **垂直構造** — バリュー チェーンの各層、各層の一般的なマージン
- **プラットフォーム/ネットワーク** — エコシステム参加者、参加者間の価値の流れ
- **断片化** — 統合のダイナミクス、規模ごとのマージンの違い

<a id="step-3--target-company-profile"></a>
### ステップ 3 — 対象企業の概要

```
| Metric | Value |
|---|---|
| Revenue | $4.96B |
| Growth | +26% YoY |
| Gross Margin | 45% |
| Profitability | $373M Adj. EBITDA |
| Customers | 134K |
| Retention | 92% |
| Market Share | ~15% |
```

マルチセグメント企業は内訳を追加します。

```
| Segment | Revenue | Rev YoY | Rev % | EBITDA | EBITDA YoY | Margin |
|---|---|---|---|---|---|---|
| Seg A | $25.1B | +26% | 57% | $6.5B | +31% | 26% |
| Seg B | $13.8B | +31% | 31% | $2.5B | +64% | 18% |
| Seg C | $5.1B | -2% | 12% | -$74M | -16% | -1% |
| Total | $44.0B | +18% | 100% | $6.5B* | - | 15% |
```
*該当する場合は本社共通費を注記します

<a id="step-4--competitor-mapping"></a>
### ステップ 4 — 競合他社のマッピング

適合するレンズごとにグループ化します (ユーザーが指定していない場合、これは `ask_user_question` の適切な決定です)。
- ビジネスモデル別 — プラットフォーム / 垂直 / 水平
- セグメント別 — エンタープライズ / SMB / コンシューマ
- 姿勢別 - 直接 / 隣接 / 出現
- 出身別 — 既存企業 / 破壊的企業 / 新規参入者

<a id="step-5--positioning-visualization"></a>
### ステップ 5 — ポジショニングの可視化

| 種類 | いつ |
|---|---|
| 2×2マトリックス | 2 つの主要な競争要因 |
| レーダー/スパイダー | 多要素比較 |
| 階層図 | 戦略的グループへの自然なクラスタリング |
| バリューチェーンマップ | 垂直産業 |
| エコシステムマップ | プラットフォーム市場 |

業界別の 2×2 軸ペアについては、`references/frameworks.md` を参照してください。

<a id="step-6--competitor-deep-dives"></a>
### ステップ 6 — 競合他社の詳細調査

競合企業ごとに 2 つのテーブル。

**メトリクス:**
```
| Metric | Value |
|---|---|
| Revenue | $X.XB |
| Growth | +XX% YoY |
| Gross Margin | XX% |
| Market Cap | $X.XB |
| Profitability | $XXXM EBITDA |
| Customers | XXK |
| Retention | XX% |
| Market Share | ~XX% |
```

**定性的:**
```
| Category | Assessment |
|---|---|
| Business | What they do (1 sentence) |
| Strengths | 2-3 bullets |
| Weaknesses | 2-3 bullets |
| Strategy | Current priorities |
```

<a id="step-7--comparative-analysis"></a>
### ステップ 7 — 比較分析

```
| Dimension | Company A | Company B | Company C |
|---|---|---|---|
| Scale | ●●● $160B | ●●○ $45B | ●○○ $8B |
| Growth | ●●○ +26% | ●●● +35% | ●●○ +22% |
| Margins | ●●○ 7.5% | ●○○ 3.2% | ●●● 15% |
```

<a id="step-8--strategic-context"></a>
### ステップ 8 — 戦略的背景

M&A取引（評価倍率、戦略的根拠）、パートナーシップの傾向、資本調達パターン、規制の動向。 M&A 取引テーブルの形式については、`references/schemas.md` を参照してください。

<a id="step-9--synthesis"></a>
### ステップ9 — 統合

**競争優位の防壁（moat）の評価** — 各競合他社を次の点で「強い」/「中程度」/「弱い」と評価します。

| 防壁 | 何を評価するか |
|---|---|
| ネットワーク効果 | ユーザー/サプライヤーのフライホイールの強度。異なる利用者層間と同一利用者層内のネットワーク効果 |
| スイッチングコスト | 技術的統合の深さ、契約上のロックイン、行動習慣 |
| 規模の経済 | 量に応じた単位コストの利点。最小効率スケール |
| 無形資産 | ブランド、専有データ、規制ライセンス、特許 |

**統合に必要な要素:**
- 永続的な利点 (再現が困難) — 防壁のカテゴリにマッピング
- 構造的な脆弱性（修正が困難）
- 現在の状態と軌跡

**投資のコンテキストについて** (フェーズ 1 の範囲設定で「いいえ」と判断された場合はスキップしてください):

```
| Scenario | Probability | Key driver |
|---|---|---|
| Bull | 30% | Market share gains, margin expansion |
| Base | 50% | Current trajectory continues |
| Bear | 20% | Competitive pressure, margin compression |
```

<a id="quality-checklist"></a>
## 品質チェックリスト

終了する前に:

**依頼内容への忠実さ**
- スライドのタイトルはユーザーが指定したものとそのまま一致します
- 彼らがチャートと言うところのチャート。彼らがテーブルと言っていたテーブル
- リストされているすべての競合他社/年/データポイントが存在します
- 指定どおりの正確な値と形式

**データの一貫性**
- ソースファイルの値は再計算されずに直接抽出されます。
- 同じ指標は、表示されるすべてのスライドで同じ値を示します
- ソースと同じ小数精度

**レイアウト**
- タイトルがオーバーフローせずに収まる
- 重複する要素はありません
- コンテナ内のすべてのテキスト、クリッピングなし

**内容**
- すべての数字には引用文が付いています
- 同じ会計期間のすべての指標 (またはフラグが設定された)
- スライドのタイトルはトピックではなく洞察を述べます
- チャートは実際のチャートオブジェクトです

すべてのスライドで標準の視覚的検証チェックを実行します。これにより、XML を読み戻すときに表示されない重複、オーバーフロー、および低コントラストのテキストが検出されます。
