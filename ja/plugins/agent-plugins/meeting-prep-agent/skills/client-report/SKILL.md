# 顧客向けレポート

<a id="workflow"></a>
## 作業手順

<a id="step-1-report-parameters"></a>
### ステップ1：レポートの条件

- **顧客名**と世帯。
- **報告期間**：四半期、年初来（YTD）、年間、任意の期間。
- **口座**：全口座または特定口座。
- **ベンチマーク**：S&P 500、60/40の混合指標、IPSに合う独自ベンチマーク。
- **会社のブランド表現**：ロゴ、色、免責事項。

<a id="step-5-market-commentary"></a>
### ステップ5：市場解説

顧客の知識水準に合わせて、短い市場の要約を書く。

- 今四半期に市場で何が起きたか（2〜3文）。
- ポートフォリオにどう影響したか。
- 見通しとポジショニングの理由（2〜3文）。
- 一般の個人顧客には専門用語を避ける。知識の豊富な投資家には、より専門的な表現を使ってよい。

<a id="step-6-activity-summary"></a>
### ステップ6：活動の要約

- 期間中に実行した取引。
- 入金と出金。
- 受領した配当と利息。
- 徴収した手数料。
- リバランスの実施内容。

<a id="step-7-planning-notes"></a>
### ステップ7：計画に関する注記

- 退職後資金、教育資金などの財務目標に向けた進捗。
- 計画の変更または推奨事項。
- 今後の行動項目。
- 次回のレビュー日。

<a id="step-8-output"></a>
### ステップ8：出力

- 会社のブランド表現を反映したPDFレポート（8〜12ページ）。
- 個別調整用のWord文書。
- Excelデータ付録（任意）。

**レポートの構成：**

1. 表紙（顧客名、期間、会社ロゴ）。
2. エグゼクティブサマリー（1ページ）。
3. 運用実績の要約（1〜2ページ）。
4. グラフを含む資産配分の概況（1ページ）。
5. 保有資産の明細（1〜2ページ）。
6. 市場解説（1ページ）。
7. 活動の要約（1ページ）。
8. 計画に関する注記（1ページ）。
9. 開示事項と免責事項（1ページ）。

<a id="important-notes"></a>
## 重要な注意事項

- 顧客またはコンプライアンス部門が控除前を要求しない限り、運用実績は手数料控除後で計算する。
- 過去の運用実績、リスク要因など、適切な免責事項・開示事項を必ず含める。
- 顧客間でレポートを統一するため、標準テンプレートを使用する。
- 顧客に合わせて詳細度を調整する。すべての保有資産を見たい顧客も、1ページの要約を望む顧客もいる。
- ベンチマークの選定は重要である。見栄えのよい指標ではなく、IPSで定められた指標を使う。
- 新しいテンプレートで初めて配布する前に、コンプライアンス承認のためのレビューを受ける。
