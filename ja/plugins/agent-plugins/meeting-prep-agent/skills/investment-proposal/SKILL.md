<a id="investment-proposal"></a>
# 投資提案書

<a id="workflow"></a>
## 作業手順

<a id="step-1-prospect-context"></a>
### ステップ1：見込顧客の背景

次を収集する。

- **見込顧客の名前**と世帯の詳細。
- **現在の状況**：既存のアドバイザーがいるか。自分で運用しているか。面談のきっかけは何か。
- **資産**：想定AUM、口座の種類、共有されていれば現在の保有資産。
- **目標**：退職後資金、資産保全、成長、収入、教育、資産承継。
- **リスク許容度**：保守的、中程度、積極的、または質問票のスコア。
- **制約**：ESGの希望、集中した株式保有、非流動性に関する要件。
- **手数料への感度**：現在いくら支払っているか。
- **競合**：ほかに誰への依頼を検討しているか。

<a id="step-2-proposal-structure"></a>
### ステップ2：提案書の構成

**I．当社について**（1ページ）

- 会社概要、沿革、AUM。
- 投資哲学を平易な言葉で説明する。
- この顧客に関係するチームの略歴。
- 顧客サービスの仕組み。面談の頻度、連絡先となる担当者。

**II．お客様のニーズの理解**（1ページ）

- 顧客の目標と懸念を言い直し、話を聞いたことを示す。
- ヒアリングで特定した、計画上の主要な検討事項。
- 顧客にとって成功とはどのような状態か。

**III．提案する投資戦略**（2〜3ページ）

- 推奨する資産配分と、その理由。
- 配分が顧客の目標とリスク許容度にどう対応するか。
- 投資手段。ETF、投資信託、個別証券、オルタナティブ。
- 税を考慮した戦略。資産を置く口座の選択、損失確定による税負担調整。

提案する配分：

| 資産クラス | 配分 | 投資手段 | 理由 |
|------------|-----------|---------|-----------|
| | | | |

**IV．期待される結果**（1〜2ページ）

- 予想成長シナリオ。保守的、中程度、楽観的。
- モンテカルロ分析による目標達成確率。
- 退職後資金や収入を重視する場合の、収入予測。
- リスク指標。最大ドローダウン、ボラティリティ。
- 現在のポートフォリオが分かる場合の比較。

**V．報酬体系**（1ページ）

- 該当する場合は段階別の、アドバイザリー報酬表。
- 組み入れるファンドの費用。
- すべてを含む総費用の見積もり。
- 業界平均との報酬比較。
- 提供価値。報酬に対して何が得られるか。

**VI．開始に向けて**（1ページ）

- 口座開設の手順。
- 資産移管の予定。
- ほかのアドバイザーから移る場合の移行計画。
- 最初の90日間に何を行うか。
- 必要書類と次の手順。

<a id="step-3-customization"></a>
### ステップ3：個別調整

- 企業幹部、小規模事業主、退職者など、見込顧客に語り口を合わせる。
- 株式保有が特定銘柄に集中している場合は、その問題を直接扱う。
- ロボアドバイザーとの比較をしている場合は、計画づくりと関係性の価値を強調する。
- 価格に敏感な場合は、手数料だけでなく、総合的な価値と結果から説明する。

<a id="step-4-output"></a>
### ステップ4：出力

- 会社のブランド表現を反映したPowerPoint（12〜15枚）。
- 面談後に渡すPDF版。
- フォローアップメール用の1ページ要約。

<a id="important-notes"></a>
## 重要な注意事項

- 定型文のように見せず、相手の具体的な状況に触れて個別の提案とする。
- 運用実績を過剰に売り込まない。現実的な期待値を設定し、プロセスを重視する。
- 予測は仮定に基づくこと、過去の運用実績などの免責事項を必ず含める。
- 移行計画は重要である。顧客はアドバイザーを変更する際の混乱を懸念する。
- 48時間以内に、提案書と明確な次の手順を添えてフォローアップする。
- 見込顧客へ提示する前に、コンプライアンス部門がレビューしなければならない。
