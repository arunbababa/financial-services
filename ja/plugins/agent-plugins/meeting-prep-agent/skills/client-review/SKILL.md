<a id="client-review-prep"></a>
# 顧客レビュー面談の準備

<a id="workflow"></a>
## 作業手順

<a id="step-1-client-context"></a>
### ステップ1：顧客の背景

次を収集または検索する。

- **顧客名**と世帯の構成員。
- **口座の種類**：課税口座、IRA、Roth、401(k)、信託など。
- 口座を合算した**総運用資産額（AUM）**。
- **投資方針書（IPS）**：目標配分、リスク許容度、制約。
- **ライフステージ**：資産形成期、退職前、退職後、資産承継。
- **前回面談日**と未完了の行動項目。

<a id="step-2-portfolio-performance"></a>
### ステップ2：ポートフォリオの運用実績

各口座および世帯合算について、次を示す。

| 指標 | QTD | YTD | 1年間 | 3年間 | 設定来 |
|--------|-----|-----|--------|--------|----------------|
| ポートフォリオのリターン | | | | | |
| ベンチマークのリターン | | | | | |
| アルファ | | | | | |

**パフォーマンス寄与度分析：**

- どの資産クラス・保有銘柄がリターンを生んだか。
- プラス寄与の上位3件と、マイナス寄与の上位3件。
- 単一の保有銘柄による影響が過大になっていないか。

<a id="step-3-allocation-review"></a>
### ステップ3：資産配分のレビュー

現在の配分と目標配分を比較する。

| 資産クラス | 目標 | 現在 | 目標との差 | 対応 |
|------------|--------|---------|-------|--------|
| 米国大型株 | | | | |
| 米国中小型株 | | | | |
| 米国外の先進国株 | | | | |
| 新興国株 | | | | |
| 債券 | | | | |
| オルタナティブ | | | | |
| 現金 | | | | |

IPSのリバランス閾値（通常3〜5%）を超える配分のずれを示す。

<a id="step-4-talking-points"></a>
### ステップ4：話すべき論点

面談の議題を作成する。

1. **市場概況**（2〜3分）：マクロ経済の背景と見通しを簡潔に説明する。
2. **ポートフォリオの運用実績**（5分）：どうだったか。なぜそうなったか。
3. **資産配分のレビュー**（5分）：リバランスは必要か。
4. **計画の更新**（5〜10分）：
   - 仕事、健康、家族、住居、教育などに変化はあるか。
   - 必要収入は変わっているか。
   - 税務状況の更新。
   - 資産承継計画の更新。
5. **行動項目**（5分）：次回面談までに何をするか。

<a id="step-5-proactive-recommendations"></a>
### ステップ5：先回りした提案

レビューに基づき、次を提案する。

- 配分のずれが閾値を超える場合の、リバランス取引。
- 損失確定による税負担調整（tax-loss harvesting）の機会。
- 現金の投資配分または引出しの計画。
- 該当する場合の、Rothへの転換の機会。
- 受取人の更新、または資産承継計画上の必要事項。
- 生命保険、就業不能保険、長期介護保険（LTC）の見直し。

<a id="step-6-output"></a>
### ステップ6：出力

- 1ページの顧客レビュー要約（WordまたはPDF）。
- ベンチマーク付きの運用実績表。
- 現在と目標を比較する資産配分の円グラフ。
- 推奨行動項目。
- 面談の議題。

<a id="important-notes"></a>
## 重要な注意事項

- 面談前に顧客を理解するため、前回面談のメモを確認する。
- 自分が話したいことより、顧客が関心を持つことから始める。
- 運用実績が悪かった場合は、隠したり取り繕ったりせず、正面から説明する。
- 必ず、明確な行動項目と日付付きの次の手順を示して終える。
- 面談メモとIPSへの変更を記録する。
- コンプライアンス：すべての資料を会社の方針と規制上の要件に適合させる。
